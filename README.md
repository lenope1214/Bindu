# Bindu 프로토타입

Godot 4.5+ (4.7.2에서 열기). 도형만 사용.

## 실행
- Mac: `run_mac.command` 더블클릭 (빌드 없이 바로 실행, 에디터 안 열림)
- 에디터: Godot에서 이 폴더의 `project.godot`을 불러와 F5.
- Windows: `git pull` 뒤 `build_windows.bat`로 다시 빌드해야 새 내용이 exe에 들어감(exe는 git에 올라가지 않음).
- 왼쪽 아래 구석의 `빈두 v버전 · 규칙 …`으로 실행 중인 빌드 버전을 확인. 최신 버전은 `project.godot`의 `config/version`.
- 버전 번호는 **배포할 때만** 올린다 (push마다 올리지 않음). 배포 전 변경은 `CHANGELOG.md` 맨 아래 `## 다음 버전 (미배포)` 절에 `- 제목` + 들여 쓴 `  - 내용`으로 쌓고, 새 것을 위에 둔다(게임 안 패치노트에 "다음 배포에 들어감"으로 보임). 배포할 때 그 절 제목을 `## 제목 (vX.Y.Z)`로 바꾸고 `config/version`을 같은 번호로 올린 뒤 태그 `vX.Y.Z`. 새 기능이 모이면 둘째 자리(0.5.0 → 0.6.0), 고치기만 하면 셋째 자리(0.5.0 → 0.5.1). 다음 배포는 v0.5.0.

- 카드를 오브젝트 위로 가져가면 바뀌는 점과 공격 범위를 미리 보여 줌. 공격방식 카드는 넣을 수 있는 오브젝트에 고리, 없는 곳에 X 표시.
- 선택지 카드에 마우스를 올리면 그 속성으로 반응이 생기는 기존 오브젝트가 빛남.
- 자동 시작(오른쪽 아래 [◀ 설정]을 펼친 버튼): 켜면 설치 후 2초 뒤 시작(오브젝트를 끄는 동안은 멈춤), 끄면 Space나 [웨이브 시작]으로 시작.
- 오브젝트에 마우스를 올리면 속성·부가효과·반응·쌓기 대가·지난 웨이브 피해량(전체 대비 몫), 구체에 올리면 체력·보호막·상태. 일시정지 중에도 볼 수 있음.
- 웨이브를 마치면 가장 많이 때린 오브젝트 위에 "최다 피해 N%". 보스가 있으면 화면 위 가운데에 체력 막대.
- 창이 포커스를 잃어도 판은 계속 진행됨.
- 이어하기: 쉬는 시간(카드 고르기·특성 고르기·웨이브 시작 전)마다 자동 저장. 게임을 꺼도 시작 화면의 [이어하기]로 그 쉬는 시간부터 이어짐(웨이브 중에 끄면 그 웨이브 앞부터). 게임 오버가 되면 저장이 지워짐. 저장 파일은 `user://run.cfg`.
- 설정(O): 음량, 글자·버튼 크기(100·115·130%, 폰은 기본 130%), 화면 흔들림, 피해 숫자, 속성 기호 표시(오브젝트·저항 구체의 색 위에 속성 첫 글자, 새 저장은 켬), 모든 구체에 체력 숫자(기본 끔: 고리만, 보스·마우스를 올린 구체는 숫자도), 처음 안내 보기, 안내 처음부터 다시 보기.
- 웨이브 중에는 오브젝트 레벨 숫자를 숨김(쉬는 시간에만).
- 첫 판(온보딩): 카드 종류가 웨이브마다 하나씩 열림 — 1·2웨이브 속성만, 3웨이브 공격방식, 4웨이브 강화, 6웨이브 연계·대격변. 새 종류가 열린 쉬는 시간엔 그 카드가 선택지에 한 장 꼭 나옴. 6웨이브에 모두 열리거나 판이 끝나면 다음 판부터는 처음부터 모두. 이어하기에도 이어짐.
- 처음 안내: 처음 생기는 일(길목, 겹치기, 새 카드 종류, 보스, 누수, 첫 반응, 저항·굳센 구체)에 위쪽 가운데 한 줄 설명. 안내마다 한 번만, 쉬는 시간 안내는 웨이브 시작까지·웨이브 중 안내는 8초. 설정에서 끄거나, [안내 처음부터 다시 보기]로 본 안내를 지우고 다음 새 판을 첫 판처럼.
- 오른쪽 설명의 반응표는 만들어 본 반응만 이름이 보이고 나머지는 "? + ?" (기록 화면 반응 도감과 같은 기록). 시작 화면의 규칙 버전 고르기는 첫 판을 끝낸 뒤에 보임(그 전엔 버전 1).
- 공격은 화면 안에 들어온 구체에만 닿음.

## 오브젝트 구조
오브젝트 = **공격방식(형태) + 속성(효과) + 강화 + 연계**. 쉬는 시간 선택지에 네 종류가 섞여 나온다.

- **새 오브젝트**: 속성 카드를 빈 곳에 놓으면 *직선탄 + 그 속성*으로 설치.
- **공격방식**: 직선탄인 오브젝트에 한 번만 넣을 수 있고 그 뒤로 고정. 같은 공격방식을 또 넣으면 레벨업(피해·속도·사거리).
- **속성**: 오브젝트 위에 놓으면 겹치기. 한 오브젝트에 3종까지(같은 속성 레벨은 무제한), 더 섞으려면 연결선으로 나눔. 모든 공격에 겹친 속성 전부의 부가효과가 붙고, 속성이 많을수록 피해 증가, 대신 종류가 늘 때마다 공격 속도가 느려짐(버전 1 기준 2종 -13%, 3종 -23%).
- **강화**: 오브젝트 위에 놓기. 종류마다 5개까지 쌓임(규칙 버전에 따라 다름). 넣을 곳이 없는 강화·공격방식 카드는 선택지에 나오지 않음.
- **연계**: 연결선(두 오브젝트), 프리즘·공명(한 오브젝트).

| 공격방식 | 형태 |
|---|---|
| 직선탄 (기본) | 정한 방향으로 탄 |
| 분사 | 부채꼴 지속 피해 |
| 관통 연사 | 작은 가시를 빠르게, 관통 |
| 물줄기 | 주기적으로 길게 뿜어 멈춰 세움(경직) |
| 연쇄 번개 | 앞쪽 구체를 치고 주변으로 튐 |
| 돌풍 | 넓은 바람, 옆으로 밀기 |
| 파편탄 | 맞으면 파편 3개 |
| 벽 | 앞에 바위 벽(최대 2개) |
| 블랙홀 | 던진 자리로 빨아들임 |
| 레이저 | 충전 후 화면 끝까지 관통 |
| 투척 장판 | 던진 자리에 속성 장판 |
| 철구 | 느리고 무거운 관통탄 |
| 음파 | 부채꼴로 퍼지는 파동 (관통, 끝에서 피해 50%) |
| 시계침 | 앞쪽 ±0.7라디안을 바늘이 왕복하며 훑음 (한 번 훑을 때 같은 구체는 한 번) |
| 혼불 | 가까운 구체를 쫓아가는 혼불 |

| 속성 | 부가효과 |
|---|---|
| 불 | 화상 |
| 나무 | 피해 20% 증가 |
| 물 | 감속 |
| 전기 | 주변으로 튀는 전류 (확률 30%) |
| 바람 | 중앙 반대쪽으로 밀어내기 |
| 얼음 | 냉기 누적 시 빙결 |
| 땅 | 기절 (확률 20%씩) |
| 어둠 | 2초간 받는 피해 +30% |
| 빛 | 치명타 2배 (확률 12%씩, 최대 60%) |
| 독 | 중독, 죽으면 주변 전염 |
| 금속 | 추가 피해 + 경직(제자리에 잠깐 멈춤) |
| 소리 | 울림: 3초간 어느 오브젝트에 맞든 울림이 쌓여 3번째마다 주변(70)에 음파 (같은 구체는 1초에 한 번) |
| 시간 | 메아리: 2초간 받은 모든 피해의 20%(레벨마다 +5%, 최대 40%)를 끝날 때 한 번 더 |
| 영혼 | 넋: 맞고 3초 안에 죽으면 확률(30%, 레벨마다 +10%, 최대 60%)로 혼불이 나와 다른 구체를 쫓음 |

| 강화 | 효과 |
|---|---|
| 다중 발사 | 공격 1개 추가 (각 55%, 쌓을수록 조금씩 줄어듦) |
| 분열 | 맞은 구체에서 약한 파편 2개 (확률 12%씩, 최대 60%) |
| 유도 | 탄이 구체 쪽으로 천천히 휨, 범위 공격은 구체 쪽으로 조금 돎 |
| 튕김 | 탄이 가까운 구체로 튐(튕긴 탄 피해 40%), 번개 +1회, 그 밖은 피해 +4% |
| 크기 | 크기·범위·사거리 +12%, 탄은 피해도 +4% |
| 속사 | 공격 속도 +10% |
| 관통 | 탄 1개 더 관통(뚫을 때마다 피해 절반), 그 밖은 피해 +6% |

| 연계 | 효과 |
|---|---|
| 연결선 | 두 오브젝트(320 이내, 버전 2는 420)를 레이저로 잇고 속성을 서로 나눔 (나눈 속성으로 반응도 생김) |
| 프리즘 | 다른 오브젝트의 탄이 지나가면 이 속성이 묻고 피해 +20% |
| 공명 | 150 안의 오브젝트 하나당 피해 +12% |

특수 반응은 공격방식과 별개로 추가 공격이 나간다. 바람·소리·시간·영혼은 3개, 나머지 속성은 4개씩.
반응 모양은 한쪽 속성이 정한다: 물이 들어간 반응은 공격 방향으로 흐르는 물길(웨이브가 시작되면 앞으로 흘러 나감), 땅은 앞쪽에 가로로 서는 벽, 소리는 앞쪽 부채꼴 파동, 시간은 잠시 뒤 같은 공격이 한 번 더, 영혼은 쫓아가는 혼불.

| 특수 반응 | 효과 |
|---|---|
| 불+나무 장작 장판 | 장작 투척, 불 장판 |
| 불+물 증기 | 물길 위 증기: 띠 전체 감속·받는 피해 증가 |
| 물+나무 덩굴 | 물길 따라 자란 덩굴: 지나가는 구체를 묶음(같은 구체는 3초에 한 번) |
| 물+전기 감전 물길 | 물길에 0.5초마다 전류 |
| 불+바람 화염 회오리 | 전진하는 불 회오리 |
| 얼음+바람 눈보라 | 주변 원형 감속·냉기 |
| 어둠+빛 일식 | 주기적 화면 전체 피해 |
| 땅+불 용암 벽 | 앞쪽 가로 불벽: 크게 느려지고 탐 |
| 독+나무 독버섯 지뢰 | 밟으면 폭발 |
| 금속+전기 레일건 | 체력이 가장 많은 구체를 조준해 화면 끝까지 관통 일격 |
| 금속+빛 광륜 | 주위를 도는 빛 칼날(레벨마다 +1), 닿으면 반드시 치명타 |
| 금속+땅 지진 | 주기적으로 주변 모두 피해·기절 |
| 전기+바람 뇌우 | 번개 구름이 앞으로 떠가며 아래 구체에 낙뢰 |
| 얼음+빛 오로라 | 5갈래 빛줄기(관통), 냉기가 크게 쌓임 |
| 땅+독 독늪 | 앞쪽 가로 독 진흙: 감속·중독 2배, 안에서 죽으면 독 폭발 |
| 어둠+독 저주 | 가까운 구체에 표식(레벨 수만큼, 표식 구체는 계속 피해), 죽으면 주변(100)에 그 구체 최대 체력 25% 피해, 표식이 옮겨 감 |
| 얼음+어둠 빙결 감옥 | 앞쪽 원 안 구체를 1.5초 멈추고 받는 피해 +50% |
| 금속+소리 종 | 3.5초마다 앞쪽 부채꼴 파동, 맞은 구체에 울림 2번 |
| 얼음+소리 파쇄 | 2.5초마다 앞쪽 파동이 냉기를 쌓고, 빙결된 구체는 깨지며 큰 피해·파편 3개 |
| 어둠+소리 침묵 | 4초마다 앞쪽 파동, 맞은 구체는 2초간 저항·굳셈이 꺼지고 보스는 부하를 못 부름 |
| 빛+시간 잔광 | 3초마다 화면 끝까지 관통하는 광선, 1.2초 뒤 같은 방향으로 한 번 더 |
| 전기+시간 되감기 번개 | 2.5초마다 앞쪽 구체부터 연쇄 번개, 1초 뒤 같은 구체들을 한 번 더 |
| 땅+시간 모래시계 벽 | 앞쪽 가로 모래 벽: 느려지고 메아리 50% |
| 물+영혼 망자의 강 | 물길 안에서 죽은 구체는 반드시 혼불이 됨 |
| 독+영혼 역병 혼불 | 혼불 2개가 쫓아가 맞힌 구체를 강하게 중독 |
| 나무+영혼 고목령 | 혼불 2개가 쫓아가 맞힌 구체를 0.7초 묶음 |

## 특성 (5웨이브마다)
보스 웨이브를 넘길 때마다 3개 중 1개를 고른다. 같은 특성을 여러 번 고를 수 있다.

| 특성 | 효과 |
|---|---|
| 화력 | 모든 피해 +15% |
| 속사 | 모든 공격 속도 +12% |
| 원거리 | 모든 사거리 +12% |
| 단단한 중앙 | 중앙 최대 체력 +3, 모두 회복 |
| 넉넉한 선택 | 쉬는 시간마다 새로고침 +1 |
| 행운 | 속성 카드가 Lv2로 나올 확률 +20% (기본 20%에서 웨이브마다 +2%, 최대 50%에 더함) |
| 회복 | 웨이브를 마칠 때마다 중앙 체력 +1 |
| 끈적한 공간 | 모든 구체 이동 속도 -8% |
| 조화 | 속성을 여러 종류 겹쳐 생기는 공격 속도 감소가 절반으로 (버전 1: 2종 -13% → -7%, 3종 -23% → -13%). 두 번 고르면 다시 절반 |

## 규칙 버전 (시작 화면에서 선택, 저장됨)
2026-10-30 결정으로 두 버전만 고른다. 버전 1은 예전 버전 2(분산: 연결 거리·무리 보너스)와 4(카드 2장·이른 특수 구체)의 좋은 점을 넣어 고쳤고, 버전 3도 공통 항목은 1과 같다. 그래서 둘을 비교하면 "상한 vs 대가"만 다르다. 고친 뒤로 최고 기록은 새로 시작하고, 그 전 기록은 기록 화면에 "이전 규칙"으로 남는다. 예전 버전 2·4와 폐기한 5로 저장된 이어하기는 버전 1로 이어진다. 수치는 `scripts/rules.gd`.

| 버전 | 바뀌는 점 |
|---|---|
| 1 기준 | 속성 3종·강화 종류별 5개. 쉬는 시간마다 카드 2장, 오브젝트 수 보너스(5개 +16%·10개 +23%, 로그 곡선), 연결선 거리 420, 저항 구체 10웨이브·굳센 구체 13웨이브부터, 11웨이브부터 체력 +5%씩 |
| 3 자유 쌓기 | 상한 없음. 대신 속성 종류마다 공격 속도 -25%(기본 -15%), 같은 강화는 쌓을수록 효과가 절반씩(1, 1.5, 1.75…). 그 밖은 버전 1과 같음 |

코드에만 남아 있는 예전 버전(봇 비교용, `RULES=2` 등): 2 분산형(속성 2종·강화 3개·무리 +6%, 지금은 같은 곡선 계수 0.15), 4 빠른 템포(체력 +8%·특수 구체 8·11웨이브·구체 1.4배). 5 조합형(강화 칸)은 2026-10-30 "너무 어렵다"는 반응으로 폐기하고 코드를 지웠다(예전 기록만 "이전 규칙"으로 남음). 경위와 새 규칙 버전을 내기 전 점검 절차는 [docs/rule-history.md](docs/rule-history.md).

## 규칙
- 구체 종류: 일반(원), 빠른(뾰족, 4웨이브~), 단단한(네모, 7웨이브~), 보스(5웨이브마다, 중앙에 닿으면 3 피해, 부하 소환. 앞 쉬는 시간에 체력·저항과 실제로 지나갈 길을 분홍 선으로 미리 보여 줌). 8웨이브부터 보호막, 12웨이브부터 분열 구체가 섞임.
- 웨이브 구체 수는 3 + 2×웨이브인데 1웨이브는 70%에서 시작해 10웨이브에 100%가 됨. 새 진입 방향이 열리는 웨이브(3·6·9·18·24)는 구체 20% 적게. 보스 부하는 첫 보스 7초마다, 웨이브가 오를수록 빨라져 13웨이브부터 4초마다.
- 누수: 중앙에 닿은 구체가 나온 화면 가장자리가 붉게 번쩍이고, 다음 쉬는 시간 안내 첫 줄에 "지난 웨이브 누수: 북동쪽 3개 · 서쪽 1개 (빠른 3, 일반 1, 중앙 -4)"처럼 어디서 무엇이 새었는지 보여 줌.
- 11웨이브부터 구체 체력이 웨이브마다 5%씩 곱으로 늘어남. 10웨이브부터 저항 구체(그 웨이브의 저항 속성은 미리 안내, 그 속성 비중만큼 피해 최대 60% 감소, 점선 고리), 13웨이브부터 굳센 구체(밀기·감속·기절·냉기 절반, 회색 쐐기).
- 군중 제어 한계: 감속은 최대 70%(보스 50%), 중앙 반대쪽으로 밀리는 거리는 여유 40만큼(천천히 회복), 기절·속박·빙결은 연달아 걸리면 100%→50%→25% 뒤 2초 면역. 보스는 기절 시간 절반.
- 무리 보너스: 오브젝트 하나당 모든 오브젝트 피해 +3%. 특수 반응 공격은 겹친 레벨 합 배율을 받지 않고 반응 레벨로만 강해짐.
- 연결선은 두 오브젝트가 320 이내(버전 2는 420)일 때만 작동. 옮겨서 멀어지면 빨간 점선으로 끊김.
- 대격변 카드(각 1%): 모든 오브젝트의 속성 또는 공격방식을 무작위로 다시 뽑음.
- 맵 5종: 평원·소용돌이·십자로·폭풍·회랑(시험, 가로 일자 길, 시작 화면에서 구체가 오는 쪽을 고름). 맵별 최고 기록, 업적으로 모양 해금.
- 보스를 처치하면 중앙 체력 +2, 새로고침 +1.
- 구체는 화면 밖에서 중앙 점으로 이동. 다음 웨이브의 진입 방향이 빨간 화살표로 미리 표시됨. 방향은 웨이브마다 유지되며 점점 늘고(4곳 뒤로 6웨이브마다 하나씩, 최대 6), 가끔 하나가 옮겨 감. 발사체로 맞혀 처치하면 점수(최대 체력×10).
- 오브젝트는 체력이 없어 부서지지 않음. 구체는 오브젝트를 그냥 지나감.
- 중앙 점 체력 10, 구체가 닿으면 -1, 0이면 게임 오버. 웨이브는 무한.
- 변경 내역은 `CHANGELOG.md`.
- 조정할 수치: `scripts/elem.gd`(속성·반응), `scripts/pattern.gd`(공격방식·강화·연계 정의), `scripts/tower.gd`의 `attack()`/`hit()`(공격·부가효과 수치), `projectile.gd`, `zone.gd`, `scripts/main.gd`의 `_start_wave`/`_spawn_orb`(난이도).

## 온라인 (패치·리더보드·통계)
서버는 `server/` (자세한 내용은 [server/README.md](server/README.md)).
```
cd server && ./setup.sh https://도메인 && docker compose up -d --build
```
- `setup.sh`가 만든 `scripts/online_config.gd`를 커밋해서 빌드에 넣으면 게임이 그 서버에 붙음. 비어 있으면 온라인 기능은 꺼짐.
- 밸런스 수치는 `https://도메인/admin`의 패치 탭에서 JSON으로 바꾸면 다음 판부터 적용(새 빌드 불필요). 통계도 같은 페이지.
- 게임의 웨이브·점수 공식을 바꾸면 `server/app/validate.py`도 맞춘다(점수 검증 상한).

## Windows exe 빌드 (Mac에서)
Finder에서 `build_windows.command`를 더블클릭하거나 터미널에서 실행.
```
./build_windows.command          # 프로젝트 폴더에 Bindu.exe, Bindu.zip
./build_windows.command --debug  # 디버그 빌드
```
- Godot을 `/Applications/Godot.app`, PATH 순으로 찾음. 다른 위치면 `GODOT=/경로/Godot ./build_windows.command`.
- 처음 한 번은 Godot 버전에 맞는 export 템플릿(약 1GB)을 자동으로 내려받아 설치.
- 결과는 pck가 내장된 단일 exe라 그 파일만 Windows로 옮기면 실행됨.

## Windows exe 빌드 (Windows에서)
탐색기에서 `build_windows.bat`를 더블클릭. 디버그 빌드는 PowerShell에서 `.\build_windows.ps1 -DebugBuild`.
- 실행 중인 Bindu.exe가 있으면 먼저 종료하고, 파일이 잠겨 있으면(백신 검사 등) 2초 간격으로 10번까지 다시 시도.
- Godot을 `$env:GODOT`, PATH, 다운로드·바탕화면·`C:\Godot`·`D:\Godot`·`D:\tools\Godot`·`%LOCALAPPDATA%\Godot` 순으로 찾음(콘솔 버전 우선). 다른 위치면 `$env:GODOT = "경로\Godot_v4.x-stable_win64_console.exe"`.
- 처음 한 번은 export 템플릿(약 1GB)을 자동 설치. 결과는 프로젝트 폴더의 Bindu.exe, Bindu.zip.
