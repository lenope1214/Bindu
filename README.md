# Bindu 프로토타입

Godot 4.5+ (4.7.2에서 열기). 도형만 사용.

## 실행
- Mac: `run_mac.command` 더블클릭 (빌드 없이 바로 실행, 에디터 안 열림)
- 에디터: Godot에서 이 폴더의 `project.godot`을 불러와 F5.
- Windows: `git pull` 뒤 `build_windows.bat`로 다시 빌드해야 새 내용이 exe에 들어감(exe는 git에 올라가지 않음).
- 왼쪽 아래 구석의 `빈두 v버전 · 규칙 …`으로 실행 중인 빌드 버전을 확인. 최신 버전은 `project.godot`의 `config/version`.

## 조작
| 키 | 동작 |
|---|---|
| 1 / 2 / 3 (숫자 패드도), 클릭 | 선택지(또는 특성) 고르기 |
| Q | 선택지 새로고침 (쉬는 시간마다 1회 + 보너스, 버튼에 남은 횟수) |

| 오브젝트 클릭 | (공격방식·강화·연계 카드) 그 오브젝트에 넣기. 연결선은 두 개 차례로 |
| 카드 고른 뒤 오브젝트 꾹 누르기·끌기 | 카드를 쓰지 않고 그 오브젝트 옮기기 (방향 유지). 멀리 있는 둘을 가까이 옮겨 연결할 때 |

| 쉬는 시간에 오브젝트 클릭 | 위치·방향 옮기기 |

| P / Esc | 일시정지 (일시정지 중 R 두 번: 처음부터) |
| M | 소리 켜기/끄기 |
| Tab / 우측 상단 버튼 | 오른쪽 설명 켜기·끄기 (저장됨) |
| H / O | 도움말 / 설정 (여는 동안 게임이 멈춤) |
| F11 | 전체 화면 |
| R / 클릭 | 게임 오버 후 다시 시작 (Esc: 메뉴) |
| 시작 화면 ←/→, ↑/↓, Enter, N | 맵 바꾸기, 규칙 버전 바꾸기, 시작. 저장된 판이 있으면 Enter는 이어하기, N 두 번은 새로 시작. 메뉴에서 모양·기록·업적·설정 |

- 카드를 오브젝트 위로 가져가면 바뀌는 점과 공격 범위를 미리 보여 줌. 공격방식 카드는 넣을 수 있는 오브젝트에 고리, 없는 곳에 X 표시.
- 선택지 카드에 마우스를 올리면 그 속성으로 반응이 생기는 기존 오브젝트가 빛남.
- 자동 시작(오른쪽 아래 버튼): 켜면 설치 후 2초 뒤 시작(오브젝트를 끄는 동안은 멈춤), 끄면 Space나 [웨이브 시작]으로 시작.
- 오브젝트에 마우스를 올리면 속성·부가효과·반응·쌓기 대가·지난 웨이브 피해량(전체 대비 몫), 구체에 올리면 체력·보호막·상태. 일시정지 중에도 볼 수 있음.
- 웨이브를 마치면 가장 많이 때린 오브젝트 위에 "최다 피해 N%". 보스가 있으면 화면 위 가운데에 체력 막대.
- 창이 포커스를 잃어도 판은 계속 진행됨.
- 이어하기: 쉬는 시간(카드 고르기·특성 고르기·웨이브 시작 전)마다 자동 저장. 게임을 꺼도 시작 화면의 [이어하기]로 그 쉬는 시간부터 이어짐(웨이브 중에 끄면 그 웨이브 앞부터). 게임 오버가 되면 저장이 지워짐. 저장 파일은 `user://run.cfg`.
- 설정(O): 음량, 화면 흔들림, 피해 숫자, 속성 기호 표시(오브젝트·저항 구체의 색 위에 속성 첫 글자, 기본 꺼짐).
- 공격은 화면 안에 들어온 구체에만 닿음.

## 오브젝트 구조
오브젝트 = **공격방식(형태) + 속성(효과) + 강화 + 연계**. 쉬는 시간 선택지에 네 종류가 섞여 나온다.

- **새 오브젝트**: 속성 카드를 빈 곳에 놓으면 *직선탄 + 그 속성*으로 설치.
- **공격방식**: 직선탄인 오브젝트에 한 번만 넣을 수 있고 그 뒤로 고정. 같은 공격방식을 또 넣으면 레벨업(피해·속도·사거리).
- **속성**: 오브젝트 위에 놓으면 겹치기. 한 오브젝트에 3종까지(같은 속성 레벨은 무제한), 더 섞으려면 연결선으로 나눔. 모든 공격에 겹친 속성 전부의 부가효과가 붙고, 속성이 많을수록 피해 증가, 대신 종류가 늘 때마다 공격 속도가 느려짐(버전 1 기준 2종 -13%, 3종 -23%).
- **강화**: 오브젝트 위에 놓기. 종류마다 5개까지 쌓임(규칙 버전에 따라 다름). 넣을 곳이 없는 강화·공격방식 카드는 선택지에 나오지 않음.
- **연계**: 연결선(두 오브젝트), 프리즘·공명(한 오브젝트).

| 공격방식 | 형태 |
|---|---|
| 직선탄 (기본) | 정한 방향으로 탄 |
| 분사 | 부채꼴 지속 피해 |
| 관통 연사 | 작은 가시를 빠르게, 관통 |
| 물줄기 | 주기적으로 길게 뿜어 밀어냄 |
| 연쇄 번개 | 앞쪽 구체를 치고 주변으로 튐 |
| 돌풍 | 넓은 바람, 옆으로 밀기 |
| 파편탄 | 맞으면 파편 3개 |
| 벽 | 앞에 바위 벽(최대 2개) |
| 블랙홀 | 던진 자리로 빨아들임 |
| 레이저 | 충전 후 화면 끝까지 관통 |
| 투척 장판 | 던진 자리에 속성 장판 |
| 철구 | 느리고 무거운 관통탄 |

| 속성 | 부가효과 |
|---|---|
| 불 | 화상 |
| 나무 | 피해 20% 증가 |
| 물 | 감속 |
| 전기 | 주변으로 튀는 전류 (확률 30%) |
| 바람 | 중앙 반대쪽으로 밀어내기 |
| 얼음 | 냉기 누적 시 빙결 |
| 땅 | 기절 (확률 20%씩) |
| 어둠 | 2초간 받는 피해 +30% |
| 빛 | 치명타 2배 (확률 12%씩, 최대 60%) |
| 독 | 중독, 죽으면 주변 전염 |
| 금속 | 추가 피해 + 넉백 |

| 강화 | 효과 |
|---|---|
| 다중 발사 | 공격 1개 추가 (각 55%, 쌓을수록 조금씩 줄어듦) |
| 분열 | 맞은 구체에서 약한 파편 2개 (확률 12%씩, 최대 60%) |
| 유도 | 탄이 구체 쪽으로 천천히 휨, 범위 공격은 구체 쪽으로 조금 돎 |
| 튕김 | 탄이 가까운 구체로 튐(튕긴 탄 피해 40%), 번개 +1회, 그 밖은 피해 +4% |
| 크기 | 크기·범위·사거리 +12%, 탄은 피해도 +4% |
| 속사 | 공격 속도 +10% |
| 관통 | 탄 1개 더 관통(뚫을 때마다 피해 절반), 그 밖은 피해 +6% |

| 연계 | 효과 |
|---|---|
| 연결선 | 두 오브젝트(320 이내, 버전 2는 420)를 레이저로 잇고 속성을 서로 나눔 (나눈 속성으로 반응도 생김) |
| 프리즘 | 다른 오브젝트의 탄이 지나가면 이 속성이 묻고 피해 +20% |
| 공명 | 150 안의 오브젝트 하나당 피해 +12% |

특수 반응은 공격방식과 별개로 추가 공격이 나간다. 불은 4개, 나머지 속성은 3개씩.
반응 모양은 한쪽 속성이 정한다: 물이 들어간 반응은 공격 방향으로 흐르는 물길(웨이브가 시작되면 앞으로 흘러 나감), 땅+불·땅+독은 앞쪽에 가로로 서는 벽.

| 특수 반응 | 효과 |
|---|---|
| 불+나무 장작 장판 | 장작 투척, 불 장판 |
| 불+물 증기 | 물길 위 증기: 띠 전체 감속·받는 피해 증가 |
| 물+나무 덩굴 | 물길 따라 자란 덩굴: 지나가는 구체를 묶음(같은 구체는 3초에 한 번) |
| 물+전기 감전 물길 | 물길에 0.5초마다 전류 |
| 불+바람 화염 회오리 | 전진하는 불 회오리 |
| 얼음+바람 눈보라 | 주변 원형 감속·냉기 |
| 어둠+빛 일식 | 주기적 화면 전체 피해 |
| 땅+불 용암 벽 | 앞쪽 가로 불벽: 크게 느려지고 탐 |
| 독+나무 독버섯 지뢰 | 밟으면 폭발 |
| 금속+전기 레일건 | 체력이 가장 많은 구체를 조준해 화면 끝까지 관통 일격 |
| 금속+빛 광륜 | 주위를 도는 빛 칼날(레벨마다 +1), 닿으면 반드시 치명타 |
| 금속+땅 지진 | 주기적으로 주변 모두 피해·기절 |
| 전기+바람 뇌우 | 번개 구름이 앞으로 떠가며 아래 구체에 낙뢰 |
| 얼음+빛 오로라 | 5갈래 빛줄기(관통), 냉기가 크게 쌓임 |
| 땅+독 독늪 | 앞쪽 가로 독 진흙: 감속·중독 2배, 안에서 죽으면 독 폭발 |
| 어둠+독 저주 | 가까운 구체에 표식(레벨 수만큼, 표식 구체는 계속 피해), 죽으면 주변(100)에 그 구체 최대 체력 25% 피해, 표식이 옮겨 감 |
| 얼음+어둠 빙결 감옥 | 앞쪽 원 안 구체를 1.5초 멈추고 받는 피해 +50% |

## 특성 (5웨이브마다)
보스 웨이브를 넘길 때마다 3개 중 1개를 고른다. 같은 특성을 여러 번 고를 수 있다.

| 특성 | 효과 |
|---|---|
| 화력 | 모든 피해 +15% |
| 속사 | 모든 공격 속도 +12% |
| 원거리 | 모든 사거리 +12% |
| 단단한 중앙 | 중앙 최대 체력 +3, 모두 회복 |
| 넉넉한 선택 | 쉬는 시간마다 새로고침 +1 |
| 행운 | 속성 카드가 Lv2로 나올 확률 +20% (기본 20%에서 웨이브마다 +2%, 최대 50%에 더함) |
| 회복 | 웨이브를 마칠 때마다 중앙 체력 +1 |
| 끈적한 공간 | 모든 구체 이동 속도 -8% |
| 조화 | 속성을 여러 종류 겹쳐 생기는 공격 속도 감소가 절반으로 (버전 1: 2종 -13% → -7%, 3종 -23% → -13%). 두 번 고르면 다시 절반 |

## 규칙 버전 (시작 화면에서 선택, 저장됨)
같은 게임을 규칙만 바꿔 비교해 보는 용도. 2026-10-29 결정으로 버전 2·4의 구체 수를 조정해 자동 플레이 평균이 버전 1(6.9웨이브)과 비슷하게 맞춤(버전 2 7.1, 버전 4 6.2). 최고 기록은 버전마다 따로 저장되고, 버전 1이 아니면 화면 위쪽에 버전이 표시됨. 수치는 `scripts/rules.gd`.

| 버전 | 바뀌는 점 |
|---|---|
| 1 기준 | 아래 규칙 그대로. 속성 3종·강화 종류별 5개, 11웨이브부터 체력 +5%씩 |
| 2 분산형 | 속성 2종·강화 종류별 3개, 무리 보너스 +6%, 연결선 거리 420 |
| 3 자유 쌓기 | 상한 없음. 대신 속성 종류마다 공격 속도 -25%(기본 -15%), 같은 강화는 쌓을수록 효과가 절반씩(1, 1.5, 1.75…) |
| 4 빠른 템포 | 버전 1 상한(속성 3종·강화 5개)에 쉬는 시간마다 카드 2장, 체력 +8%씩, 저항 구체 8웨이브·굳센 구체 11웨이브부터, 구체 수 1.4배 |

## 규칙
- 구체 종류: 일반(원), 빠른(뾰족, 4웨이브~), 단단한(네모, 6웨이브~), 보스(5웨이브마다, 중앙에 닿으면 3 피해, 부하 소환). 8웨이브부터 보호막, 10웨이브부터 분열 구체가 섞임.
- 11웨이브부터 구체 체력이 웨이브마다 5%씩 곱으로 늘어남. 12웨이브부터 저항 구체(그 웨이브의 저항 속성은 미리 안내, 그 속성 비중만큼 피해 최대 60% 감소, 점선 고리), 15웨이브부터 굳센 구체(밀기·감속·기절·냉기 절반, 회색 쐐기).
- 군중 제어 한계: 감속은 최대 70%(보스 50%), 중앙 반대쪽으로 밀리는 거리는 여유 40만큼(천천히 회복), 기절·속박·빙결은 연달아 걸리면 100%→50%→25% 뒤 2초 면역. 보스는 기절 시간 절반.
- 무리 보너스: 오브젝트 하나당 모든 오브젝트 피해 +3%. 특수 반응 공격은 겹친 레벨 합 배율을 받지 않고 반응 레벨로만 강해짐.
- 연결선은 두 오브젝트가 320 이내(버전 2는 420)일 때만 작동. 옮겨서 멀어지면 빨간 점선으로 끊김.
- 대격변 카드(각 1%): 모든 오브젝트의 속성 또는 공격방식을 무작위로 다시 뽑음.
- 맵 4종: 평원·소용돌이·십자로·폭풍. 맵별 최고 기록, 업적으로 모양 해금.
- 보스를 처치하면 중앙 체력 +2, 새로고침 +1.
- 구체는 화면 밖에서 중앙 점으로 이동. 다음 웨이브의 진입 방향이 빨간 화살표로 미리 표시됨. 방향은 웨이브마다 유지되며 점점 늘고(4곳 뒤로 6웨이브마다 하나씩, 최대 6), 가끔 하나가 옮겨 감. 발사체로 맞혀 처치하면 점수(최대 체력×10).
- 오브젝트는 체력이 없어 부서지지 않음. 구체는 오브젝트를 그냥 지나감.
- 중앙 점 체력 10, 구체가 닿으면 -1, 0이면 게임 오버. 웨이브는 무한.
- 변경 내역은 `CHANGELOG.md`.
- 조정할 수치: `scripts/elem.gd`(속성·반응), `scripts/pattern.gd`(공격방식·강화·연계 정의), `scripts/tower.gd`의 `attack()`/`hit()`(공격·부가효과 수치), `projectile.gd`, `zone.gd`, `scripts/main.gd`의 `_start_wave`/`_spawn_orb`(난이도).

## Windows exe 빌드 (Mac에서)
Finder에서 `build_windows.command`를 더블클릭하거나 터미널에서 실행.
```
./build_windows.command          # 프로젝트 폴더에 Bindu.exe, Bindu.zip
./build_windows.command --debug  # 디버그 빌드
```
- Godot을 `/Applications/Godot.app`, PATH 순으로 찾음. 다른 위치면 `GODOT=/경로/Godot ./build_windows.command`.
- 처음 한 번은 Godot 버전에 맞는 export 템플릿(약 1GB)을 자동으로 내려받아 설치.
- 결과는 pck가 내장된 단일 exe라 그 파일만 Windows로 옮기면 실행됨.

## Windows exe 빌드 (Windows에서)
탐색기에서 `build_windows.bat`를 더블클릭. 디버그 빌드는 PowerShell에서 `.\build_windows.ps1 -DebugBuild`.
- 실행 중인 Bindu.exe가 있으면 먼저 종료하고, 파일이 잠겨 있으면(백신 검사 등) 2초 간격으로 10번까지 다시 시도.
- Godot을 `$env:GODOT`, PATH, 다운로드·바탕화면·`C:\Godot`·`D:\Godot`·`D:\tools\Godot`·`%LOCALAPPDATA%\Godot` 순으로 찾음(콘솔 버전 우선). 다른 위치면 `$env:GODOT = "경로\Godot_v4.x-stable_win64_console.exe"`.
- 처음 한 번은 export 템플릿(약 1GB)을 자동 설치. 결과는 프로젝트 폴더의 Bindu.exe, Bindu.zip.
