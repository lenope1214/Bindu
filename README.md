# Bindu 프로토타입

Godot 4.5+ (4.7.2에서 열기). 도형만 사용.

## 실행
- Mac: `run_mac.command` 더블클릭 (빌드 없이 바로 실행, 에디터 안 열림). 항상 GitHub main 최신을 받아(`~/Library/Caches/Bindu-main`) 실행하고, 이 폴더 그대로 실행하려면 `LOCAL=1 ./run_mac.command`
- 에디터: Godot에서 이 폴더의 `project.godot`을 불러와 F5.
- Windows: `git pull` 뒤 `build_windows.bat`로 다시 빌드해야 새 내용이 exe에 들어감(exe는 git에 올라가지 않음).
- 왼쪽 아래 구석의 `빈두 v버전 · 규칙 …`으로 실행 중인 빌드 버전을 확인. 최신 버전은 `project.godot`의 `config/version`.
- 버전 번호는 **배포할 때만** 올린다 (push마다 올리지 않음). 배포 전 변경은 `CHANGELOG.md` 맨 위 `### 다음 버전 (미배포)` 절에 `- 제목` + 들여 쓴 `  - 내용`으로 쌓고, 새 것을 위에 둔다(게임 안 패치노트에는 보이지 않음. `## `가 아니고 첫 버전 절보다 앞이라 옛 빌드도 읽지 않음). 배포할 때 그 절을 맨 아래로 옮기고 제목을 `## 제목 (vX.Y.Z)`로 바꾸고 `config/version`을 같은 번호로 올린 뒤 태그 `vX.Y.Z`. 새 기능이 모이면 둘째 자리(0.5.0 → 0.6.0), 고치기만 하면 셋째 자리(0.5.0 → 0.5.1). 다음 배포 번호는 현재 버전과 변경 규모에 맞춰 정한다.

| 속성 카드 → 빈 곳 | 기본 자동 조준 일반 판은 즉시 설치. 연습 판·자동 조준 꺼짐은 위치→방향 확정 |
| 오브젝트 클릭 | (공격방식·강화·연계 카드) 그 오브젝트에 넣기. 연결선은 두 개 차례로 |

| Shift (방향 고를 때) | 15도 단위로 맞추기 |
| 우클릭 / Esc / 화면 아래 [취소] | 한 단계 되돌리기 (카드를 고른 뒤·옮기는 중에 버튼이 뜸, 터치 화면용) |
| (터치) 오브젝트 누르기 | 선택·정보 유지. [여러 개 선택]·[전체 선택]으로 그룹 관리, [방향 변경]으로 편집 |
| Alt 누르고 있기 (터치: 오른쪽 위 [범위 보기]) | 모든 오브젝트의 공격 범위와 이번(지난) 웨이브 피해 몫(%) 보기 (끄는 동안에는 옮기는 오브젝트 범위가 보임). 터치 버튼은 누를 때마다 켜기·끄기 |
| 쉬는 시간에 오브젝트 클릭 | 선택·정보 유지. 방향은 [방향 변경] 또는 E, Alt+휠은 15도 회전(Shift 5도) |
| 오브젝트 끌기 | 방향은 그대로 두고 바로 옮기기 |
| 카드의 [정보] | 카드 소비 없이 전체 설명·대상별 변화 비교. [이전]·[다음]으로 비교하고 [이 카드 들기]로 실행 |
| 되돌리기 / Ctrl·Cmd+Z | 싱글 쉬는 시간의 최근 이동·회전·마지막 카드 적용 복원. 새 카드 공개·재추첨·특성·웨이브 시작·진행 동기화 뒤에는 이전 이력 초기화 |
| Tab·Shift+Tab / 방향키 / Enter | 오브젝트 순환 선택 / 쉬는 시간 선택 대상 이동·설치 위치 조절 / 설치·적용 확정 |
| 지난 웨이브 | 쉬는 시간에 놓친 구체의 방향·종류·실제 체력 손실 열람 |
| 빈 곳 끌기 (상자) / Shift·Ctrl+클릭 / Ctrl+A | 여러 개 선택(더하기·빼기, Ctrl+A는 모두). 선택한 것 하나를 끌면 함께 이동, 놓을 수 없는 자리면 모두 제자리. Esc/우클릭: 선택 해제 |
| Space | 웨이브 시작(자동 시작 끔) / 웨이브 중 빠르게 켜기·끄기. 배율(x2·x3·x4·x6·x8)은 오른쪽 아래 설정 버튼을 펼쳐 목록에서 선택 |
| P / Esc | 일시정지. 일시정지 중 T(또는 버튼): 시작 화면으로, X: 게임 끄기(PC), R 두 번: 처음부터. 쉬는 시간에 나가면 그대로, 웨이브 중에 나가면 그 웨이브 앞 쉬는 시간부터 이어하기 |
| M | 소리 켜기/끄기 |
| Tab / 우측 상단 버튼 | 오른쪽 설명 켜기·끄기 (저장됨) |
| 오른쪽 위 [일시정지] / P | 즉시 정지·재개. 소리·자동 시작·배속은 오른쪽 아래 설정 줄 |
| H / O | 도움말 / 설정 (여는 동안 게임이 멈춤) |
| F11 | 전체 화면 |
| 클릭 / R / Esc | 게임 오버(판 끝냄) 뒤 시작 화면으로 |
| 시작 화면 ←/→, ↑/↓, Enter, N | 맵 바꾸기, 규칙 버전 바꾸기, 시작. 저장된 판이 있으면 Enter는 이어하기, N 두 번은 새로 시작. 메뉴에서 모양·기록·업적·설정 |

- 일반 판 화면: 전장은 중앙, 카드는 하단 고정 도크, 카드 설명은 오른쪽. 카드에 마우스를 올리거나 카드 [정보]를 열면 적용 가능한 오브젝트에 얇은 고리, 새 반응이 생기는 곳에 반응색 고리를 표시. 카드 [정보]에서 소비 없이 전체 조건과 적용 대상을 비교하며, 정보창의 이전·다음으로 카드를 바꿔 읽는다. 선택·설치·전투 중 전장 위치와 배율은 같고, 실제 전장 크기·사거리는 그대로.
- 카드를 오브젝트 위로 가져가면 바뀌는 점과 공격 범위를 미리 보여 줌. 공격방식 카드는 넣을 수 있는 오브젝트에 고리, 없는 곳에 X 표시.
- 선택지 카드에 마우스를 올리면 그 속성으로 반응이 생기는 기존 오브젝트가 빛남.
- 자동 시작(오른쪽 아래 [◀ 설정]을 펼친 버튼): 켜면 설치 후 2초 뒤 시작(편집·명시적 오브젝트 선택·상세 읽기 동안은 보류), 끄면 Space나 [웨이브 시작]으로 시작.
- 오브젝트에 마우스를 올리면 속성·부가효과·반응·쌓기 대가·지난 웨이브 피해량(전체 대비 몫), 구체에 올리면 체력·보호막·상태. 일시정지 중에도 볼 수 있음.
- Alt (터치: 오른쪽 위 [범위 보기])를 누르면 공명 오브젝트의 적용 반경(금색 원)도 표시.
- 웨이브를 마치면 가장 많이 때린 오브젝트 위에 "최다 피해 N%". 보스가 있으면 화면 위 가운데에 체력 막대.
- 싱글 판은 포커스를 잃으면 기본 정지하고 돌아온 뒤 직접 재개한다. 설정에서 변경 가능. 멀티 판은 다른 참가자와 계속 진행된다.
- 이어하기: 쉬는 시간(카드 고르기·특성 고르기·웨이브 시작 전)마다 자동 저장. 게임을 꺼도 시작 화면의 [이어하기]로 그 쉬는 시간부터 이어짐(웨이브 중에 끄면 그 웨이브 앞부터). 게임 오버가 되면 저장이 지워짐. 게임 버전(구석의 vX.Y.Z)이 바뀌면 지난 버전의 판은 이어 하지 않고, 켤 때 그 판을 지금 점수로 끝내 결과를 보여 줌(기록·온라인 전송은 그 판의 버전으로). 저장 파일은 `user://run.cfg`.
- 설정(O): 음량, 글자·버튼 크기(100·115·130%, 폰은 기본 130%), 화면 흔들림, 피해 숫자, 속성 기호 표시(오브젝트·저항 구체의 색 위에 속성 첫 글자, 새 저장은 켬), 모든 구체에 체력 숫자(기본 끔: 고리만, 보스·마우스를 올린 구체는 숫자도), 처음 안내 보기, 안내 처음부터 다시 보기.
- 웨이브 중에는 오브젝트 레벨 숫자를 숨김(쉬는 시간에만).
- 첫 판(온보딩): 카드 종류가 웨이브마다 하나씩 열림 — 1·2웨이브 속성만, 3웨이브 공격방식, 4웨이브 강화, 5웨이브 발동, 6웨이브 연계. 새 종류가 열린 쉬는 시간엔 그 카드가 선택지에 한 장 꼭 나옴. 모두 열리거나 판이 끝나면 다음 판부터는 처음부터 모두. 이어하기에도 이어짐.
- 처음 안내: 처음 생기는 일(길목, 겹치기, 새 카드 종류, 보스, 누수, 첫 반응, 저항·굳센 구체)에 위쪽 가운데 한 줄 설명. 안내마다 한 번만, 쉬는 시간 안내는 웨이브 시작까지·웨이브 중 안내는 8초. 설정에서 끄거나, [안내 처음부터 다시 보기]로 본 안내를 지우고 다음 새 판을 첫 판처럼.
- 오른쪽 설명의 반응표는 만들어 본 반응만 이름이 보이고 나머지는 "? + ?" (기록 화면 반응 도감과 같은 기록). 시작 화면의 규칙 버전 고르기는 첫 판을 끝낸 뒤에 보임(그 전엔 버전 1).
- 공격은 화면 안에 들어온 구체에만 닿음.

## 오브젝트와 전투 규칙

오브젝트는 공격방식·속성·강화·발동·연계로 구성된다. 속성 카드를 빈 곳에 놓으면 새 오브젝트, 기존 오브젝트 위에 놓으면 겹치기다. 공격방식·상한·상성·추가 효과와 실제 수치는 게임 안 도감·카드 [정보]에 표시한다.

기본 자동 조준은 지키는 곳에 가까운 위험한 구체를 먼저 겨눈다. 위험도가 비슷한 구체끼리는 정한 방향을 선호하며 날아가는 탄은 이동을 예측한다. 기본 자동 조준에는 피해 감소가 없고, 이전 반응 강화 카드는 선택지에서 제외된다. 방향 선호는 오브젝트를 선택해 별도로 편집한다.

- 현행 동작과 검증: [기능 명세](docs/features.md).
- 맵·모드: [맵 규칙](docs/map-rules.md), [모드](docs/modes.md).
- 규칙 변경 이력: [규칙 이력](docs/rule-history.md). 오래된 README의 고정 수치·삭제된 반응 표는 [이전 문서](docs/archive/legacy-readme-rules-2026-11-09.md)로 보존했다.
- 개발 구조와 QA: [아키텍처](docs/architecture/main-refactor.md), [검사 도구](tools/README.md).

## 온라인 (패치·리더보드·통계)
서버는 `server/` (자세한 내용은 [server/README.md](server/README.md)).
```
cd server && ./setup.sh https://도메인 && docker compose up -d --build
```
- `setup.sh`가 만든 `scripts/online_config.gd`를 커밋해서 빌드에 넣으면 게임이 그 서버에 붙음. 비어 있으면 온라인 기능은 꺼짐.
- 밸런스 수치는 `https://도메인/admin`의 패치 탭에서 JSON으로 바꾸면 다음 판부터 적용(새 빌드 불필요). 통계도 같은 페이지.
- 패치 탭의 카드 사용 여부 표에서 속성·공격방식·강화·발동·연계·특성을 `1`(사용) 또는 `0`(미사용)으로 바꿀 수 있음. 새 게임 빌드와 패치 서버 배포가 필요하며, 속성 카드는 하나 이상 켜 둬야 함.
- 게임의 웨이브·점수 공식을 바꾸면 `server/app/validate.py`도 맞춘다(점수 검증 상한).

## macOS 설치형 앱 빌드

```sh
./build_macos.command
# 일반 배포용 Developer ID 서명·공증
MACOS_SIGN_IDENTITY='Developer ID Application: ...' MACOS_NOTARY_PROFILE=bindu ./build_macos.command
```

- Xcode 명령행 도구와 libarchive 헤더(`brew install libarchive`) 필요. Godot 내보내기 템플릿은 없으면 자동 설치.
- 결과: `build/macos/Bindu.app`, `build/macos/Bindu-macos.zip` (Intel·Apple Silicon 공용).
- 기본은 로컬 QA용 ad-hoc 서명. 일반 배포본은 Developer ID 서명·공증 후 배포.
- 설치형 앱은 시작 화면 [업데이트]로 다운로드·앱 교체·재시작. 기존 Windows 업데이트 서버를 재사용하며 Sparkle은 사용하지 않음.
- 개발용 `run_mac.command`의 main 소스 실행 흐름은 그대로. 설치형 앱과 배포·업데이트 방식이 다름.
- 릴리스 등록·실패 복구·검증: [서버 안내](server/README.md), [도구 안내](tools/README.md).

## Windows exe 빌드 (Mac에서)
Finder에서 `build_windows.command`를 더블클릭하거나 터미널에서 실행.
```
./build_windows.command          # 프로젝트 폴더에 Bindu.exe, Bindu.zip
./build_windows.command --debug  # 디버그 빌드
```
- Godot을 `/Applications/Godot.app`, PATH 순으로 찾음. 다른 위치면 `GODOT=/경로/Godot ./build_windows.command`.
- 처음 한 번은 Godot 버전에 맞는 export 템플릿(약 1GB)을 자동으로 내려받아 설치.
- 결과는 pck가 내장된 단일 exe라 그 파일만 Windows로 옮기면 실행됨.

## Windows exe 빌드 (Windows에서)
탐색기에서 `build_windows.bat`를 더블클릭. 디버그 빌드는 PowerShell에서 `.\build_windows.ps1 -DebugBuild`.
- 실행 중인 Bindu.exe가 있으면 먼저 종료하고, 파일이 잠겨 있으면(백신 검사 등) 2초 간격으로 10번까지 다시 시도.
- Godot을 `$env:GODOT`, PATH, 다운로드·바탕화면·`C:\Godot`·`D:\Godot`·`D:\tools\Godot`·`%LOCALAPPDATA%\Godot` 순으로 찾음(콘솔 버전 우선). 다른 위치면 `$env:GODOT = "경로\Godot_v4.x-stable_win64_console.exe"`.
