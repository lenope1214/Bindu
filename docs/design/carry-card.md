# 카드를 들고 전장에 적용하기

PR #13의 카드·전장 레이아웃을 보완한다. 기준 `dc7366c`.

- 전장 카메라는 실제 화면 크기와 사용자 확대/이동만 따른다. 카드 목록·상세·패널 접기·글자 배율·안전 영역은 카메라 배율에 관여하지 않는다. 논리 전장과 게임 수치는 유지한다.
- 일반 판 카드를 한 번 누르면 미적용 상태로 든다. 목록과 상세는 접히고, 커서 옆 또는 손가락 위에 그림·카드 이름만 표시한다. 적용 가능한 오브젝트·새 반응·넣기 전후 미리보기는 전장에 남는다.
- 든 카드를 대상에 클릭/터치하거나, 목록에서 직접 끌어 대상에 놓는다. 유효 대상에서만 한 번 적용하며 남은 선택은 이때 차감한다. 무효 대상·UI·전장 밖에 놓으면 카드를 계속 든다.
- 속성 카드를 빈 곳에 놓으면 발사 방향을 정하는 기존 단계로 간다. 방향 취소는 위치 선택으로, 위치 취소는 원래 카드 목록으로 돌아간다.
- 우클릭·Esc·화면 취소 버튼으로 같은 목록과 남은 선택·선택 표시를 복원한다. 되돌릴 때 새로 추첨하거나 새로고침 횟수를 쓰지 않는다.
- 카드 드래그 도중 취소·일시정지·앱 전환·두 번째 손가락 확대가 시작되면 뒤늦은 release로 적용하지 않는다. 터치와 흉내 낸 마우스 이벤트가 중복 적용되지 않도록 제스처를 구분한다.
- 카드 상세와 오브젝트 정보는 기존 오른쪽 설명을 떠 있는 패널로 사용한다. 카드를 든 동안은 숨기고, 읽을 때만 노출하며 카메라에는 영향을 주지 않는다.
- 정원은 기존 상점과 터치 두 단계 구매를 유지한다. 특성 등 즉시 효과 선택에도 대상 드래그를 요구하지 않는다.
- 적용 전 앱을 종료하면 마지막 저장된 같은 선택 목록·남은 장수로 복원한다. 실제 게임 저장 공간은 QA에서 사용하지 않는다.

검증: `tools/spec_check.gd` UI-14·UI-28·UI-29·UI-30·UI-31·TUT-06과 `tools/carry_check.gd`. native 검사는 PC 100/130%·폰 안전 영역, 실제 GUI 클릭·드래그·터치·취소·앱 전환·확대·일시정지와 화면 겹침을 확인한다. `tools/dock_check.gd`는 전장을 축소하던 이전 고정 도크 비교 도구이므로 이번 계약의 실행 검증은 `carry_check.gd`를 사용한다.
