# 하단 카드 도크

기준: main 0c8e15b. 일반 판의 카드가 전장 오브젝트를 가리는 문제를 해결한다.

- 중앙 전장, 하단 고정 도크, 오른쪽 고정 정보 영역. 선택·설치·방향·대기·전투·일시정지에서 전장 프레이밍을 유지한다.
- 논리 전장 1280×720, 설치 좌표, 사거리, 구체 이동과 수치는 그대로. 카메라만 남은 화면에 맞춘다. 전장의 화면상 크기는 작아진다.
- 카드 세 장은 낮은 가로형. 이름과 요약을 앞면에, 전체 조건과 반응은 오른쪽 스크롤 영역에 제공한다. 효과 원문은 변경하지 않는다.
- 마우스 hover/터치 미리보기에서 적용 가능한 대상과 새 반응 대상을 구분한다. 협동 상대의 소유권과 요청 조건도 적용한다.
- 하단과 오른쪽 영역은 전장 누르기·드래그·확대로 통과하지 않는다. 취소, V 보기, 적용, 새로고침, 넘기기, 키 선택은 유지한다.
- 기존 짙은 남색(#0b101a)·얇은 구분선·속성색 강조, Apple SD Gothic Neo/Noto Sans CJK KR/Malgun Gothic. 전장 어두운 막은 일반 판에서 없앤다.
- 정원은 별도 상점과 전장 카메라가 있어 이번 변경에서 제외한다. 기존 미병합 PR #6/#8/#9는 포함하지 않는다.

검증: 동일 fixture의 전후 캡처, PC 100/130%, 폰 안전 영역/터치 모의, 태블릿. 전장 전체·하단/사이드 분리, 카메라 안정성, 입력 좌표 역변환, 취소/이어하기/특성/줌, UI 겹침·잘림, 기존 기능 검사 및 종합 검사 결과를 기록한다. 실제 모바일 기기와 사용자 이해도는 별도 검증이다.
