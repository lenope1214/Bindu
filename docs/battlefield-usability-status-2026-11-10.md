## 600개 조합 결과

범위는 **이어하기 요약의 레이아웃**이다. PC/폰 모의 ×5배율 ×멀티 타일 표시 여부2 ×맵5 ×규칙2 ×저장 웨이브 자릿수3으로 구성했다.

| 범위 | 조합 수 | 수정 전 잘림 | 수정 후 잘림 |
|---|---:|---:|---:|
| PC | 300 | 150 | 0 |
| 폰 모의 | 300 | 0 | 0 |
| 전체 | 600 | 150 | 0 |

같은 도구·최신 제품 소스 해시를 확인했다. 추가 폭/문구 복귀20상태와10프로필의 가상 Enter 새 판/저장/이어하기도 통과했다. 원래 들어가던450조합의 버튼 크기도 보존됐다. 기본 PC 문구는 하단9px이 잘리던92px 타일에서117px 타일로 바뀌었다. [전후·전체 원자료·범위](qa/2026-11-09-battlefield-fixes/continue-tile/README.md).

현재 캡처에는 ‘랭/크’ 낱말 분리와 일부 PC 시작 화면의 기존 자동 맞춤에 따른 최대 약4.6% 축소가 남는다. 사람의 읽기 품질까지 완료한 결과로 보지 않는다.

최신 공통 검사는 명세252·전달86·전투345사례/4140표본·fuzz4×3000·W4/8/12→13을 통과했다. 서버 검사는 의존성 부재로 건너뛰었고, 일회성 아키텍처 감사는 기존41개/새 실패0이다. 이를 서버 포함 전체 gate 통과로 부르지 않는다.
