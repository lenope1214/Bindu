# 개선 요청 및 진행 상태

사용자 요청과 현재 main에 반영된 상태를 기록한다. 이 릴리스는 현재 main의 최신 멀티플레이·맵 규칙 구현을 기준으로 한다.

1. **완료 — 맵 보너스 효과 안내**: 준비 화면과 웨이브 예고에 맵별 고유 규칙·친화 카드·효과 수치를 표시한다.
2. **완료 — 보스 웨이브 위험 표시**: 예고에 중앙 피해 경고를 강조하고, 기존 경로·체력·저항·부하·도착 시간 안내를 유지한다.
3. **검토 필요 — 초록 궤적 삭제**: 최신 main에는 맵 장판·그린 궤적 편집 기능이 함께 존재한다. 어느 시각 효과를 말하는지 분리해 삭제해야 하므로 이 배포에서 임의로 공격 패턴/편집 기능을 제거하지 않는다.
4. **완료 — 공격 방향 즉시 반영**: 이동 방향 확정과 조준 미리보기에서 공격 방향·총구 표시를 함께 갱신하고, 취소 시 원래 방향으로 복구한다.
5. **기존 지원 — 인앱 업데이트**: Windows 단일 실행 파일은 서명·해시 검증 후 인앱 업데이트한다. 다른 플랫폼·에디터 실행은 배포 페이지를 연다.
6. **완료 — 공명 범위 표시**: Alt 또는 터치 `[범위 보기]`에서 실제 공명 반경(현재 규칙·맵 보정 포함)을 금색 원으로 표시한다.
7. **완료 — 배경 음악**: 외부 음원 없이 합성한 낮은 음량 반복 음악을 추가했다. `M`으로 음악과 효과음을 함께 제어한다.
8. **기존 지원 — 멀티 준비 현황**: 최신 main의 대기방에 참가자 명단·연결 상태·준비 인원 수와 호스트 시작 가능 여부가 표시된다.

## 1번 구현 메모

시작 화면의 맵 설명에 플레이 방식과 실제 수치 보정을 함께 표시한다. 해당 보정은 `scripts/main.gd`의 웨이브 생성·구체 생성 로직을 기준으로 한다.

## 배포 메모

v0.7.4에는 현재 main의 멀티 로비 현황 표시도 포함한다. 3번은 대상 효과를 정확히 특정할 때까지 보류한다.

## 점검

Godot 4.7.2에서 에디터 헤드리스 로드 및 프로젝트 짧은 실행을 확인했다. Android 빌드 도구 경로 경고와 종료 시 ObjectDB 정리 경고가 있었으나 스크립트 오류는 없었다.
