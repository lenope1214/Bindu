# UI 개선안

2026-11-03 게임 화면 캡처를 기준으로 정리했다. 한 장의 캡처에서 확인할 수 있는 겹침과 정보 밀도를 우선 처리하고, 다른 화면 크기에서도 같은 문제가 있는지 후속 점검한다.

## 우선순위

### P0 — 전장 위 설명 겹침

- **관찰:** 오브젝트의 상세 정보 상자가 전장 위에 크게 떠서 적의 진입 경로와 오브젝트를 가린다. 카드 선택 중에는 카드·전장 안내와 동시에 보인다.
- **개선:** 카드 도크가 활성화된 동안 오브젝트 정보를 오른쪽 고정 설명 칸에 표시한다. 설명할 카드·특성·오브젝트가 없으면 칸을 숨긴다. 전장 위에는 공격 범위 미리보기만 남기고, 상세 수치와 계산 내역은 설명 칸에서 스크롤해 읽게 한다.
- **완료 기준:** 카드 선택 중 오브젝트에 마우스를 올려도 정보 상자가 카드나 전장 위에 뜨지 않고, 기본 정보와 자세한 수치를 모두 확인할 수 있다. 내용이 없을 때 빈 설명 칸도 보이지 않는다.

### P1 — 다음 웨이브 안내 배지 정리

- **관찰:** 진입 방향마다 숫자·몬스터 종류·NEW 표시가 붙어 배지가 여러 곳으로 흩어지고, 일부가 경로와 오브젝트 가까이에 놓인다.
- **개선:** 카드 선택 중과 모바일에서는 각 방향에 구체 수와 새 종류 표시만 두고, 종류·저항·보스 세부 정보는 배지를 가리켜 확인하게 한다. 배지는 UI와 오브젝트를 피해 가장자리 쪽 빈 자리에 놓는다.
- **완료 기준:** 배지가 UI와 오브젝트를 피해 배치되고, 배지를 가리키거나 터치해 해당 방향의 웨이브 정보를 확인할 수 있다.

### P1 — 상단 HUD 정보 계층

- **관찰:** 웨이브·점수·중앙 체력·기록·맵·규칙·통계·특성 등 여러 칩이 한 줄에 이어져 어떤 값이 급한지 한눈에 구분하기 어렵다.
- **개선:** 웨이브·점수·중앙 체력은 첫 줄에 유지하고, 기록·맵·규칙·부가 통계는 다음 줄로 분리한다. 위험 상태는 색과 아이콘으로 강조한다.
- **완료 기준:** 일반 창과 와이드 화면에서 핵심 전투 상태가 먼저 읽히고, 칩이 겹치거나 화면 밖으로 나가지 않는다.

### P2 — DPS 표와 필드 공간

- **관찰:** 왼쪽 DPS 표가 전장 위에 넓게 자리 잡아 길목 안내와 겹칠 수 있고, 접힌 상태에서도 눈에 띄는 제목 줄이 남는다.
- **개선:** 카드 선택 중에는 DPS 표를 접어 제목만 남기고, `D`를 누르면 상세 목록을 펼친다. 도크와 겹치지 않도록 표의 카드 가림 영역을 제한한다.
- **완료 기준:** 표가 길목 배지·카드·도움말과 겹치지 않고, 접었을 때 전장 공간을 돌려준다.

### P2 — 카드 선택과 설명 칸의 역할

- **관찰:** 아래 카드 줄, 오른쪽 설명 칸, 전장 위 정보가 동시에 많은 내용을 보여 준다. 사용자가 어느 곳을 읽어야 할지 분산된다.
- **개선:** 카드에는 선택에 필요한 핵심 효과만, 오른쪽 칸에는 적용 대상·새 반응·상세 설명을 둔다. 전장에는 적용 가능한 오브젝트 강조만 표시하고, 도크가 켜져 있을 때 카드 전체 설명 팝업은 중복 표시하지 않는다.
- **완료 기준:** 카드 하나를 미리 볼 때 적용 대상과 효과를 찾기 쉽고, 같은 설명이 여러 위치에 중복되지 않는다.

### P3 — 글자·색 대비 및 화면 크기

- **관찰:** 어두운 전장 위에 반투명 패널과 여러 색의 텍스트가 겹치며, 작은 보조 글은 큰 화면에서도 상대적으로 흐리다.
- **개선:** 본문·보조 글·비활성 정보의 대비 단계를 통일하고, UI 배율별로 패널 여백과 줄바꿈을 조정한다.
- **완료 기준:** 기본 UI 배율과 큰 글자 설정에서 잘림·겹침 없이 읽을 수 있다.

### 전체 전장 보기

- **요청:** 카드·설명 패널이 전장 공간을 차지할 때 패널을 접어 전체 전장을 보고 싶다.
- **개선:** PC는 `F` 키로 아래 카드 도크와 오른쪽 설명 칸을 접고 다시 연다. 접은 동안에는 되돌리기 버튼만 화면 모서리에 남긴다. 모바일은 같은 버튼을 화면에 항상 두고, 접으면 화면 모서리에 고정해 다시 열 수 있게 한다.
- **완료 기준:** 전환 중에도 선택 중인 카드와 게임 진행 상태가 유지되고, 한 번의 입력으로 패널을 복구할 수 있다.
- **모바일 고려:** 키보드 단축키를 요구하지 않는다. 터치 가능한 고정 버튼을 사용해 패널을 접고 복구한다.

## 진행 상태

- **구현 완료·화면 점검 대기:** 카드 도크가 보이는 동안 오브젝트 정보를 오른쪽 설명 칸에 표시하고, 전장 위 상세 상자는 숨긴다. Shift 상세 내용도 오른쪽 칸에서 스크롤해 읽을 수 있다. 카드 선택 중 방향 배지의 몬스터 아이콘을 접어 구체 수 중심으로 보여 준다.
- **구현 완료·화면 점검 대기:** 내용이 없는 오른쪽 설명 칸은 숨긴다. PC `F` 키와 모바일 화면 버튼으로 아래·오른쪽 패널을 접고 전장 보기로 전환하며, 접은 상태에서 복귀 버튼을 제공한다.
- **구현 완료:** 카드 선택·모바일에서 방향별 웨이브 배지를 구체 수와 신규 종류 점으로 간소화하고, 배지가 UI·오브젝트를 피해 배치되도록 한다. 배지를 가리키거나 터치하면 전체 정보를 볼 수 있다.
- **구현 완료:** 웨이브·점수·중앙 체력을 HUD 첫 줄에 두고 기록과 부가 지표를 다음 줄로 분리한다. 카드 선택 중 DPS는 기본 접힘 상태로 두며 `D`로 펼친다.
- **구현 완료:** 카드 전체 설명은 오른쪽 설명 칸을 사용할 때 한 곳에서만 보이도록 한다. 상세 설명은 오른쪽 칸에서 읽고 적용 대상은 전장 강조로 확인한다.
- **후속 화면 점검:** 글자 배율·화면 크기별 대비와 패널 여백을 실제 실행 화면에서 확인한다.
