# 판마다 다른 흐름 (0.6.0 시험)

2026-10-31 사용자 요청: "웨이브가 진행될수록 최고점이 하나로 수렴할 것 같다. 매판 같은 흐름이 되지 않게 변동성을 추가하자."
기획안(후보 8개 A~H): https://claude.ai/artifact/EA5E3QWyiPnP3Z4x7P8Fn8. 사용자가 A 봉인 + C 웨이브 이벤트 + D 적응 구체를 1차로 골랐고, D는 "40%면 아예 못 쓰게 되니 최대 20%로 시작, 추후 폭을 올리자".

근거(실제 플레이 44판, 2026-10-31): 혼불 선택률 61%(버전마다 오름), 영혼·어둠·빛이 속성 1~3위, 공격방식을 끝까지 직선으로 둔 판 66%, 협공을 고른 판에서 협공 피해 19%.

## 규칙

| 장치 | 동작 | 패치 키 (`rules.all`) |
|---|---|---|
| 봉인 | 새 판 시작 때 속성 3·공격방식 4·연계 1을 무작위로 뺌. 선택지·대격변에 안 나옴. 25·50웨이브 쉬는 시간에 하나씩 풀림 | `vary_seal_elem` `vary_seal_pat` `vary_seal_link` |
| 웨이브 이벤트 | 9웨이브 뒤 예고 → 10웨이브 뒤부터 10웨이브 동안. 같은 이벤트 연달아 없음. 속성·공격방식 ±40%, 도파민 ±60% | `vary_event_every` `vary_event_k` |
| 적응 구체 | 30웨이브부터 직전 5웨이브 피해 1위 속성(레벨 몫)·1위 공격방식에 +2%/웨이브, 1위가 아니면 -2%/웨이브. 오브젝트 피해 감소 합 최대 20% | `vary_adapt_from` `vary_adapt_step` `vary_adapt_max` |

이벤트: 일식(빛↓ 어둠↑) · 백야(어둠↓ 빛↑) · 기운의 흐름(속성 둘↑ 하나↓) · 형태의 날(공격방식 둘↑ 하나↓) · 황금 무리(처치 점수 x2, 구체 속도 +15%) · 굳은 껍질(모두 굳셈, 체력 -15%) · 증식(모두 분열, 체력 -25%).

끄는 곳: 첫 판(튜토리얼)·멀티플레이·정원. `vary_on` 0이면 전부 끔. 봇은 `VARY=0`으로 끔.

## 측정·남은 일

- 봇(규칙 1, 32판, 같은 시드, 2026-10-31): 끔 중간값 18·평균 17.9 → 켬 14·16.9 (평균 x0.94, 중간값 -4로 compare 기준 "어려움"에 걸림. 켜면 난수 순서가 달라 판마다 짝이 안 맞아 흔들림이 큼). 봇은 30웨이브 넘는 판이 적어 적응 구체는 거의 못 잼.
- 1주 뒤 서버 detail.vary로 봉인 판의 공격방식 선택률 분포·평균 웨이브를 이전 판과 비교. 혼불 선택률이 내려가고 평균 웨이브가 -2 안쪽이면 정식, 적응 상한은 그 뒤 올릴지 정함.
- 2차 후보: B 징조(판 수식어), H 오늘의 판(날짜 시드 리더보드).
