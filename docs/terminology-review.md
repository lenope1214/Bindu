# 용어 검토 (2026-11-05)

검토 범위: 속성·효과·특징·상성, 공격방식·강화·연계·발동, 특성·모드·맵·중앙 기술의 이름과 설명, 특징 조합 이름 생성 규칙. 사전 등재 여부가 아니라 이름만 보고 동작을 이해할 수 있는지 판단했다. 온라인 운영자 덮어쓰기는 검토 범위 밖이다.

## 반영

- ~~곁공격~~ → **보조 공격**, ~~큰 곁공격~~ → **큰 보조 공격**. 화면·피해 출처·패치노트·문서·관리자 표·검사·주석을 통일했다. 저장·온라인 패치에 쓰는 식별자는 유지한다.

## 추가 발견: 승인된 교정안과 반영 상태

| 교정 전 표현 | 문제 | 반영 문구 | 원본 |
|---|---|---|---|
| 얼려 오래감 | 동작과 결과를 억지로 줄인 표현. 무엇이 오래가는지 불명확 | ~~얼려 오래감~~ → **지속 시간 연장**. 반영: 효과·얼림 시간과 냉기를 그대로 보존 | `scripts/elem.gd` TRAIT[ICE] |
| 혼불은 목줄 +15% | 실제 목줄을 표시하지 않아 무엇이 늘어나는지 알기 어려움 | ~~목줄~~ → **추적 범위**. `Projectile.wisp_leash`가 오브젝트 기준 추적 범위를 계산함. 현재 `Pat.NO_MOD[homing]`은 혼불을 제외하므로 카드 설명의 +15% 예외 문장 자체도 낡았음 | `scripts/pattern.gd` MODS[homing] |
| 비친 상 / 다져진 비친 상 / 날선 비친 상 | 옆 오브젝트의 다음 공격에 효과를 싣는 기능이 드러나지 않음. 조합 자동 생성이 어색함을 증폭 | ~~비친 상~~ → **효과 전달**로 통일하고, 환영 조합에는 속성 제목·문장형 설명 반영 | `scripts/share.gd` SITE_NOUN·MOD_ADJ·site_name |
| 날선 | 합성 조합 이름의 띄어쓰기 문제 | ~~날선~~ → **날 선** | `scripts/share.gd` MOD_ADJ[METAL] |
| 자양 | 조어 문제보다는 의미 전달 문제. 무엇이 강해지는지 이름만으로 알기 어려움 | ~~자양~~ → **성장 촉진** 반영 | `scripts/elem.gd` AFF_RULES[nourish] |

‘혼불’, ‘기맥’, ‘공진’, ‘초신성’ 등은 낯설 수 있다는 이유만으로 잘못된 조어로 분류하지 않았다. 게임 고유 개념·물리 현상·비유의 이름과, 기능을 숨기는 불명확한 표현은 구분한다. 추가 변경 시 고유 이름과 관련 설명을 함께 바꾸고 수치·조건을 보존해야 한다.

## 반영 기록

- ~~얼려 오래감~~ → **지속 시간 연장**. 효과·얼림 시간 **1.5배**, 냉기 적용 설명 보존.
- ~~목줄~~ → **추적 범위**. 혼불 수와 추적 범위를 나눠 표시. ~~혼불은 목줄 +15%.~~ 문장 삭제, 유도 적용 제외에 **혼불** 명시. 기존 저장값 처리와 전투 수치는 유지.
- ~~날선~~ → **날 선**, ~~자양~~ → **성장 촉진**. 성장 촉진 설명은 **나무의 거리별 피해 증가 상한이 +30%에서 +50%로 늘어나요.**로 교정.
- ~~비친 상~~·~~옆 오브젝트에 비춤~~ → **효과 전달**. 환영 16짝은 **환영 · 속성** 제목과 전달 동작 설명을 조합 카드·도감·상세에서 함께 사용. ~~다져진 비친 상~~ → **환영 · 땅**, ~~날선 비친 상~~ → **환영 · 금속**.

검증: 최종 상태에서 명세 238개와 PC 100%·130%, 폰 안전 영역·터치 130%, 태블릿 터치 130%의 전체 카드 588개 캡처 검사 통과. 환영 16짝은 네 화면 조건에서 제목·동작 설명 공용 여부, 줄바꿈, 화면 안 배치·버튼 분리, 두 장 표시 또는 한 장+더 보기를 별도 검사해 통과했다. 검사 도구는 `tools/card_writing_check.gd`와 `tools/illusion_text_check.gd`다. 모두 데스크톱 모의이며 실기기 검증은 아니다.
