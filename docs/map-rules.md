# 맵별 규칙·친화 카드 (시험)

2026-10-31 사용자: "맵별로 특색이 약해 결국 한 맵만 할 것 같다". 기획안: https://claude.ai/artifact/RRJPanDo3zXTgunhbRgGk1 (1차 추천안 승인).
근거(서버 58판): 소용돌이 평균 53·폭풍 48·회랑 31·평원 24웨이브, 십자로 0판. 같은 기기에서 평원 15~17 → 소용돌이 55~69. 혼불(유도)은 길 모양과 상관없어 어느 맵이든 최선.

코드: `scripts/maprule.gd` (MapRule). 수치는 온라인 패치 `rules`의 `map_*` 키, `map_on` 0이면 끔. 정원은 없음. 봇은 `MAPRULE=0`으로 끔.

바람·회전 방향은 진입 방향·웨이브 번호에서 정해져 따로 저장하지 않는다(멀티·이어하기 같음).
