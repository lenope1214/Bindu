# 사용성 개선 5개 항목

2026-11-04. 항목별 커밋으로 카드 패널 조작 통합, 인스펙터 닫기·Esc, 선택/방향 편집 분리, 넘기기 단위, 조작 상태 표시를 검증한다. 최종 렌더 캡처는 마지막 UI 변경 뒤 보존한다.

1. 패널: 눈 버튼을 없애고 하단 버튼 하나와 F/V가 같은 `cards_hidden` 상태를 토글한다. 기존 내부 `hide_btn` 참조는 같은 버튼의 별칭으로 유지한다. 전체 spec 208개 통과 (`01-panel-spec.log`).

실기기·실제 OS 입력·배포는 검증하지 않았다.

2. 인스펙터: 스크롤 밖 헤더에 ×를 두고 닫기 시 선택/대상/터치 참조를 정리한다. 같은 오브젝트 위에서 Esc를 눌러도 재호버 전에는 다시 열지 않는다. Esc는 진행 중 조작, 선택/상세, 일시정지 순으로 처리한다. 전체 spec 208개 통과 (`02-inspector-spec.log`).

3. 오브젝트: 클릭은 선택·상세로 한정하고 내 오브젝트 하나를 선택한 쉬는 시간에 [방향 변경]을 노출한다. 편집 취소는 원래 방향·선택 복원, 확정은 선택 해제. 전투 중에는 읽기 전용이다. 카드가 접혀 있어도 오브젝트 상세는 읽을 수 있다. spec 209개 통과 (`03-selection-spec.log`), PC 가상 GUI 입력·Esc 3단계·×·끌기·터치 회귀 `CARRY failures=0 ui=0` (`03-selection-ui.log`).

4. 넘기기: 수 선택을 `N웨이브 ▸`로 표시하고, 실행 툴팁에 지금 보류할 카드 선택·새로고침(특성 중에는 특성 1회)을 안내한다. 실행과 수 변경은 같은 연결 그룹이며 수만 바꾸면 시작하지 않는다. spec 209개 통과 (`04-skip-spec.log`).
