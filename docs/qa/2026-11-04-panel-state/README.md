# 선택지 복원·인스펙터 유지·배속 그룹

2026-11-04, `codex/card-tooltip-controls`. 별도 문구 수정 커밋 `37b654d` 위에서 이번 UI 변경만 검증했다.

## 수정

- 숨긴 선택지의 복원 버튼을 매 프레임 숨겼다가 다시 표시해 press 상태를 취소하던 로직을 수정했다. 버튼·V를 같은 토글로 연결하고, F 접기에서도 V로 복원한다. 선택지와 남은 장수는 그대로 유지한다.
- 접힌 설정 줄의 빈 HBox 영역이 다른 버튼의 클릭을 가로채지 않게 했다. 설정 줄이 펼쳐지면 복원 버튼을 그 위로 올린다.
- 실제 새 오브젝트 호버는 유지된 카드 미리보기보다 우선한다. 오브젝트 정보는 빈 공간과 인스펙터로 이동해도 유지하고, 패널 내부 클릭·스크롤은 전장으로 넘기지 않는다. 새 카드·특성 호버, 카드 선택, 대상 삭제·장면 종료에서 참조를 갱신/정리한다. 대상 변경 시 스크롤도 초기화한다.
- 유지된 인스펙터가 알림·배너와 겹치지 않도록 후보 위치를 보정했다. 기존 구석 배치를 유지하며 커서를 따라다니는 방식은 추가하지 않았다.
- 배속 실행 버튼과 속도 선택을 간격 없는 HBox 연결 그룹으로 묶고 넘기기와 같은 분할 테두리 스타일을 재사용한다. 기존 배속 토글·설정·Space 동작은 유지한다.

## 최종 검증

Godot 4.7.2 macOS arm64. 저장 이름 `BinduToolsPanelState`, 온라인·멀티 주소를 비운 사본에서 실행했다. `source-hashes.json`의 검사 대상 파일은 검사 시점 작업 트리와 사본을 바이트 대조했다. 커밋 대상도 이 사본의 해시와 대조했으며, 이후 시작된 별도 포인터 입력 변경은 제외했다. 문구 수정은 이 커밋에서 변경하지 않으며, 이미 커밋된 문구 수정과의 통합 상태도 최종 검사했다.

| 검사 | 결과 | 근거 |
|---|---|---|
| 전체 spec | 207개 기능, 실패 0 | `spec.log` |
| PC 1280×720, UI 100% | `CARRY failures=0 ui=0` | `desktop.log` |
| PC 1280×720, UI 130% | `CARRY failures=0 ui=0` | `large.log` |
| 폰 모의 1560×720, UI 130%, 60fps 제한 | `CARRY failures=0 ui=0` | `phone.log` |

폰 안전 영역은 좌우 86·하단 38이다. Native 각 22개 화면, 총 66개 캡처를 실행하고 대표 6장을 보존했다. PC·큰 글자·폰 인스펙터와 스크롤 상태·복원 버튼과 설정 줄의 분리·배속 그룹을 직접 확인했다.

- 설정 줄 접힘/펼침에서 버튼 열기·닫기와 V 열기·닫기를 각각 3회 반복한다. 동일 선택지·남은 장수 및 F→V 복원을 확인한다.
- 카드 호버 종료 후 유지, 오브젝트로 교체, 빈 공간 통과, 패널 내부 이동, 긴 상세의 휠 스크롤, 다른 오브젝트/카드로 교체, 카드 들기와 취소, 삭제 대상 정리를 확인한다. 휠 입력은 press/release를 짝지어 주입한다.
- 배속 셀렉트는 실제 GUI 클릭으로 팝업을 열고 `PopupMenu.index_pressed`로 항목 선택 신호를 주입한다. 선택만 바꿔도 1배속이 유지되는지, 실행 버튼으로 선택 배속이 적용되는지, Space로 돌아오는지 확인한다. 엔진의 해당 연결은 [Godot OptionButton 구현](https://github.com/godotengine/godot/blob/4.7/scene/gui/option_button.cpp)을 확인했다.
- 기존 카드 클릭·드래그·터치·무효 드롭·취소·앱 전환·두 손가락 확대·일시정지·카메라 독립 검사도 통과했다.

## 검증 한계

입력은 native 창에 주입한 합성 Mouse/Touch 이벤트다. 중간 실행에서 첫 클릭·기존 터치 취소/확대 검사가 간헐 실패했다. 원인을 모두 확정하지는 않았다. 창 활성화·입력 진입 대기를 추가했고 폰은 60fps 제한으로 최종 검사했다. 실패 이력 중 최종 통합 상태의 제한 없는 폰 실행도 `phone-intermittent.log`에 보존한다. 최종 세 실행의 실패 0이 반복 재현성을 보장하지는 않는다.

실기기·실제 멀티·서버 테스트·전체 배포 검사·배포는 실행하지 않았다. 일부 종료에 기존 ObjectDB 정리 경고가 남는다. 현재 실행 중인 게임은 새 컨트롤 트리가 만들어지도록 재실행해야 한다.

## 재실행

저장 이름과 온라인 주소를 분리한 사본에서 실행한다.

```sh
"$GODOT" --headless --path "$QA_COPY" -s tools/spec_check.gd
"$GODOT" --path "$QA_COPY" --resolution 1280x720 -s tools/carry_check.gd -- "$OUTPUT/desktop" 1.0
"$GODOT" --path "$QA_COPY" --resolution 1280x720 -s tools/carry_check.gd -- "$OUTPUT/large" 1.3
"$GODOT" --path "$QA_COPY" --max-fps 60 --resolution 1560x720 -s tools/carry_check.gd -- "$OUTPUT/phone" 1.3 phone
```
