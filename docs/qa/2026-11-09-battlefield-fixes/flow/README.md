# 진행·기술·저장 사용성 수정

담당 범위: BF-07·08·26·27·30–33·35–40 및 BF-46·47·50의 설정·상태 API. 공유 UI·입력·프레임 연결은 root 소유다.

## 구현

- `Meta.pause_on_focus_loss=true`, `Meta.skill_aim_slow=true` 추가. 설정 화면에서 변경하고 기존 저장 파일의 설정에 보존한다. 설정 체크박스는 키보드 포커스를 받는다.
- `abilities.skill_speed_factor()`: 옵션이 켜진 싱글 수동 기술 조준은 0.25, 멀티·봇 자동 기술·비조준은 1.0. 실제 프레임 배율 적용은 root가 연결한다.
- 기술 버튼에 효과·준비/실제 약 N초 표시, 툴팁에 게임 시간·배속·웨이브 재충전 명시. `skill_auto_btn`에서 수동·자동을 직접 변경한다. 자동 발동 때는 그 사실을 알린다.
- 진행 수는 `open_skip_picker()`의 1·3·5·10 직접 선택. `set_skip_n(n)`은 카드나 전투를 소비하지 않는다. `연속 진행`으로 실제 전투·카드 보류 의미를 드러내고 진행 배지에 특성·카드·새로고침 수와 현재 웨이브 뒤 멈춤을 표시한다.
- `_toggle_speed(from_shortcut=false)`는 시작 뒤 450ms 동안 단축키 가속만 차단한다. 명시적 배속 버튼은 즉시 작동한다.
- 초기 구현에서 편집용 메모리 저장 API를 시험했으나 통합 검토에서 제거했다. 편집 복원은 `BinduEditHistory`가 기존 Node와 런타임을 보존하고, 저장 검사는 실제 `_save_run()`→`_continue_run()` 경로로 분리한다. 아래 초기 로그의 메모리 스냅샷 항목을 최종 undo 증거로 사용하지 않는다.
- `save_status_text()`는 실제 로컬 저장 성공과 전투 중 복원 지점, 멀티/연습 판의 이어하기 부재를 구분한다. 저장 실패 뒤에는 성공이라고 표시하지 않고 온라인 저장도 요청하지 않는다.
- `multiplayer_status_text()`는 내 준비 필요/완료·친구 대기·전투·연결 실패·소유권 및 속성 요청 예외를 설명한다. 실제 상태를 만드는 네트워크 프로토콜은 변경하지 않는다.
- 도움말의 자동 조준·방향 선호·명시적 방향 편집·Alt+휠·키보드 조작·같은 속성 Lv 상한을 현행 동작에 맞춘다.
- 시작·연속 진행·다시 불러오기·게임 오버·새 판의 저장 삭제 경계에서 root의 편집 이력을 지운다.

## 검증

- [수정 전 로그](before.log): 7개 단언 실패, 종료 코드 1. API 부재·모호한 진행/기술 표시를 확인했다.
- [PC 100%](pc.log): 31개 단언 통과, `BATTLEFIELD FLOW failures=0 ui=0`, 종료 코드 0.
- [폰 모의 130%](phone.log): 31개 단언 통과, `BATTLEFIELD FLOW failures=0 ui=8`, 종료 코드 0. 8개 경고는 설정 모달과 뒤 HUD의 겹침이다. 해당 경고를 8개 제품 결함으로 세지 않았다.
- 최종 로그에 `SCRIPT ERROR`·`ERROR:` 없음. 일부 도구 종료에서 기존 `ObjectDB` 2개 경고가 남는다.
- native 프로세스는 종료 코드 0을 관찰했고 임시 프로젝트는 `tools/run.sh`의 종료 정리 경로로 제거됐다. 운영 서버 URL·멀티 URL은 공백, 저장은 `BinduTools` 전용이었다.
- [캡처·소스 해시](manifest.json). 무작위 카드·길목을 이용한 픽셀 전후 비교 자료는 아니다.

확인 과제: 직접 진행 수 선택의 무소비, 카드/점수/ID/배치/피해 기록의 메모리 복원, 복원 중 파일 불변, 잘못된 스냅샷 거부, 설정 기본값·사용자 꺼짐 유지, 실제 쿨다운·수동/자동 전환, 멀티 이어하기 부재, 시작 직후 Space 중복 입력 방지와 명시적 배속 버튼 반응.

VirtualInput은 실제 창 포커스를 건드리지 않도록 포커스 정지 옵션을 테스트에서 끈다. 새 저장의 기본값은 빈 ConfigFile을 별도로 로드해 검증하고 기존 테스트 설정으로 되돌렸다. WAVE 캡처는 잔여 spawn을 남겨 비어 있는 합성 전투가 즉시 클리어되지 않게 했다.

## root 통합 뒤 확인할 것

- 폰 `continuous.png`의 기술 버튼은 텍스트 최소 너비를 고려한 그룹 배치 재검증이 필요하다. 자동 UI 검사는 그려진 글자 겹침을 모두 찾지 못한다.
- `save_status_text()`는 일시정지에 연결됐지만 평소 화면의 저장 경계 접근은 root UI 연결이 필요하다.
- `multiplayer_status_text()`의 공유 HUD 연결·실통신 두 참가자 준비/요청/복귀 검증은 root 작업이다.
- BF-07 실제 OS 전환, BF-47 전화·잠금·강제 종료, BF-49 실제 중급 폰 부하, BF-50 전체 기기·색각·대비 검증은 이 묶음으로 통과를 주장하지 않는다.
- 전체 `tools/run.sh check`, 변경 명세·기존 검사 갱신, 통합 native·실기기 확인은 root 최종 gate다.
