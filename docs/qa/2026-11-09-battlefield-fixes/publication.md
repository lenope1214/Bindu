# PR에 포함한 증거와 로컬 원본

PR에는 진단 원본73장, 수정·검증 문서가 직접 연결하는 캡처/로그/JSON, 최신 통합 집계·소스 manifest, 실제 재실행에 필요한 Python/GDScript 도구, 대표 최신 화면을 포함한다. 실행 중 생긴 반복 캡처·중간 trace 원본을 모두 Git 이력에 넣지는 않는다.

전체 원본은 이 작업 폴더에 그대로 보존한다. 삭제하거나 덮어쓰지 않았다. `publication-manifest.json`은 모든 원본의 상대 경로·크기·SHA-256과 PR 포함 여부를 기록한다. 포함되지 않은 경로는 GitHub에서 내려받을 수 있는 파일이라고 주장하지 않는다. 일부 집계 JSON 안의 세부 PNG/trace 경로는 이 로컬 원본을 가리킨다.

로컬 원본 중 커밋하지 않은 파일만 `.git/info/exclude`의 이 작업 전용 구간에 정확한 파일 경로로 기록한다. 테스트 코드·재실행 도구와 이후 생성할 다른 이름의 파일을 포괄적으로 숨기지 않는다. 관계없는 `tools/side_shot.gd.uid`는 별도로 보존하고 커밋에 포함하지 않는다.
