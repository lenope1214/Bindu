# 사용성 버그 개별 수정 검증

기준 `44092b4`, 수정 브랜치 `codex/usability-input-fixes`. 이전 재현값은 `before.json`. 저장 분리·온라인 주소 비움·VirtualInput/no_focus 검사만 사용한다. 실기기·실제 멀티 통신·배포는 미검증.

1. 모바일 상세: 기존 오브젝트 자세히 버튼을 고정 인스펙터 헤더로 옮기고 실제 유지 대상을 기준으로 상세 상태를 유지한다. 시간 경과·패널 터치 후에도 자세히/간단히와 상세 범위가 같은 대상을 가리킨다. UI-16의 오래된 3초 닫힘 명세도 최신 유지 요구로 갱신. 명세 211개, 폰 130% 가상 터치 검사 통과.

2. 협동 소유권: Ctrl+A는 기존 내 오브젝트 목록을 사용한다. 그룹 드래그 시작 시 선택의 소유권을 다시 확인하고, 누르는 중 소유권이 맞지 않으면 중단한다. 혼합 선택을 주입해도 내 것만 이동하고 친구 좌표는 보존됨. 명세 211개·가상 마우스 검사 통과.

3. 일시정지 입력: 정지 중 게임 단축키를 메뉴·표시 조작과 구분해 차단하고, 넘기기/새로고침 진입점도 정지를 확인한다. P→S/Q/Space/1과 직접 호출로 선택·새로고침·목록이 보존되고 P 재개 후 S가 정상 실행됨. 명세 212개·가상 키 입력 통과.

4. 방향 편집 종료: 카드 선택 취소 경로를 호출하지 않고 이전 CHOOSE/READY와 접힘 상태로 복귀한다. 확정 시 선택·상세·이전 카드 미리보기 정리, 취소 시 원래 방향·선택 복원. 같은 카드가 offer에 남아 있는 펼침/접힘 두 경우 모두 가상 클릭 검사 통과. 명세 212개 통과.

5. 정지 중 열람: 표시 차단과 편집 차단을 구분한다. 인스펙터를 정지 막보다 그리기·GUI 입력 순서 모두 위에 두고 메뉴를 피한다. 자세히 터치·휠 스크롤은 가능하고 편집은 금지한다. 정지 시 진행 중 드래그를 원위치로 취소하고 정지 중 위치/방향 미리보기로 배치를 변경하지 않는다. 명세 213개, 폰 130% 읽기·스크롤·드래그 취소 검사 통과.

6. 겹침 입력: 실제 버튼·패널 → 그려진 칩/배지 → 전장 순으로 처리한다. 원래 터치와 마우스 에뮬레이션의 누름·뗌을 각각 소비하고, UI 위에서 끝난 오브젝트 이동·상자 선택은 적용하지 않는다. 앱 포커스 상실 시 정보 입력 소유권도 초기화한다. 진단의 반복 재현·수정 후 비교는 `06-input-diagnosis.md`, `06-click-before.log`, `06-click-after.log`에 보존했다.

최종 검증: 명세 213개, 사용성 전체(PC 100%·폰 130%), 기존 carry 전체(PC 130%·폰 130%) 모두 실패 0·UI 겹침/잘림 0. 모달 밖 클릭·버튼 뒤 대상·배지 뒤 대상·드래그 UI 종료·에뮬레이션 on/off 포함. 무작위 입력 2판 × 3,000프레임 오류 0. 화면과 로그는 `06-*`, `phone/`, `pc130/`. 기존 UI 도구 종료의 ObjectDB 2개 경고는 남아 있다. 실기기·실통신 멀티·배포는 수행하지 않았다.

7. 명세 정리: 처음 안내가 보일 때 상태 줄을 생략하는 기존 우선순위를 UI-35에 명시하고 안내 전/표시 중 상태 변화를 검사했다. UI-16의 오래된 3초 닫힘은 1번 수정에서 정리했다. 최종 명세 213개 통과. 제품 동작 변경 없음.
