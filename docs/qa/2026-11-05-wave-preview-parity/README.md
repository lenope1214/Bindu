# 길목 경고와 공격 미리보기 대조 검증

Godot 4.7.2, 격리 프로젝트·가상 입력 사용. 실제 게임 저장 파일·OS 커서·포커스를 사용하지 않았다.

[전체 검사 로그](check.log): 명세 238개·기본/처치 대조·튜토리얼·무작위 입력 4×3000프레임·이어하기·온라인·패치 표 통과. 최종 일식 렌더링 추출은 이후 [렌더링 검사](gallery.log)로 별도 확인했다.

## 길목 경고

- 미방어 길목의 시작 차단 제거. 카드 선택 단계부터 해당 배지에 `새 진입`·`범위 밖`을 표시.
- PC 100%, 폰 모의 환경 130%에서 두 방향·여섯 방향을 검사. 여섯 배지 모두 카드·서로·화면 밖을 피한다.
- PC 클릭과 폰 모의 터치로 경고가 있는 웨이브를 시작. 멀티 준비·튜토리얼 진행·이어하기는 전체 검사로 확인.
- [PC 로그](lanes-pc.log), [폰 로그](lanes-phone.log), [폰 화면](lanes-phone.png).

## 이전 미리보기에서 발견한 누락

- `wave_active` 누락으로 분사·물줄기·레이저·음파·시계침의 실제 공격 그림이 그려지지 않았다.
- 주변 배치가 없어 공명·협공·별빛·무리 보너스가 달랐다. 실제 위치·방향을 대체해 맵/기맥 판정도 달라질 수 있었다.
- 축적·삼연·별빛의 누적 상태 복사, 처치 축적, 일부 효과 타이머가 누락됐다.
- 8초마다 초기화해 오래 걸리는 발동과 누적 상태를 잘랐다.

지금은 주변 배치와 진행 상태를 복사하고, 실제 월드 좌표를 유지한 채 카메라만 회전한다. 실제 이동·타이머·공격·명중·처치 효과·렌더링 코드를 공유한다. 8초 초기화 대신 예시 표적만 보충한다. 점수·업적·저장은 실행하지 않는다.

## 실제 전투와 수치 대조

`preview_parity_check.gd`는 같은 시드·배치·표적에서 실제 `_sim_step`과 인스펙터 `advance`를 각각 실행한다. 20프레임마다 피해·출처·상태 이상·발사체 위치/속도/피해/크기·장판·축적/삼연/별빛 등을 대조한다. 허용 반올림 단위는 0.00001이다. 카메라·음향·콤보 점수 말풍선의 난수는 전투 비교에서 제외한다.

| 검사 | 사례 | 비교 시점 | 결과 |
| --- | ---: | ---: | --- |
| 기본·레벨·강화 9종·발동 6종·별/행성/주변 연계 × 공격 15종 | 300 | 3,600 | 일치 |
| 조합 136개 × 공격 15종 | 2,040 | 24,480 | 일치 |
| 처치 후 독 전염·혼불·축적·여진 × 공격 15종 | 45 | 540 | 일치 |

| 합계 | 2,625 | 31,860 | 불일치 0 |

실행: `GODOT=/Applications/Godot.app/Contents/MacOS/Godot tools/run.sh preview basic` (`pairs`, `deaths`, `context`, `long`도 동일). `check`에는 기본·처치 비교를 포함한다.

- [전체 조합](pairs.log), [맵·방향](context.log), [장시간](long.log), [처치 효과](deaths.log).
- 별도 명세 검사로 실제 판의 점수·중앙 체력·구체 수·피해 기록 격리, 8초 이후 상태 유지·표적 보충, X 닫힘·명시적 재활성화를 확인했다.

## 실제 렌더링

`preview_gallery.gd`로 15개 공격방식의 초기·명중 이후 화면 30장을 캡처했다. 분사·물줄기·레이저·음파·시계침은 본체 앞 영역의 픽셀이 전투/비전투 상태에서 달라지는지도 확인했다. 앞선 실행 스모크 검사만으로는 찾지 못했던 공격 그림 누락을 잡는 검사다.

[공격방식 모음](gallery.png), [렌더링 로그](gallery.log).

일식 화면 연출이 미리보기 영역 안을 덮는지도 픽셀로 확인했다.

## 범위와 한계

- 유한한 사례 검사이며 모든 레벨·강화 중첩·세 속성 이상 조합·특수 적·시간 순열을 전수 검증한 것은 아니다. 알려진 모든 공격방식은 별도 모사 그림 없이 실제 전투 및 그리기 경로를 사용한다.
- 예시 표적 배치다. 실제 웨이브의 적 배치·종류나 확률 결과를 녹화 재생하는 기능은 아니다. 표적·확률·처치 조건이 충족되지 않으면 해당 효과가 매 반복에 반드시 나오지는 않는다.
- 실기기·실제 멀티플레이·배포·GPU 성능 벤치마크 미검증. 서버 Python 검사는 의존성 부재로 생략.
- 일부 native 도구 종료 시 ObjectDB 잔존 경고가 있다. 통과 로그에 실행 중 SCRIPT ERROR는 없다.

검사 도구의 무작위 우클릭이 텍스트 메뉴를 열며 OS 클립보드를 조회하는 문제도 수정했다. 자동화 Viewport 안의 텍스트 컨트롤에서만 문맥 메뉴를 비활성화하며, 실제 게임의 텍스트 입력 동작은 바꾸지 않는다. 무작위 입력 상세 로그도 check 임시 결과에 보존한다.
