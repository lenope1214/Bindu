# PR 15 main 병합 검증

main의 UI 다시 그리기 최적화를 기능 컨트롤러 구조로 이식했다. main 진입점은 유지하고, 조건부 테마·앵커 변경과 도크 단일 배치, 정보층 변경 감지를 보존했다. 길목 경고가 방향·강화·새 길목 변화에도 갱신되도록 감지 입력을 확장했다.

- 전체 check 통과: 명세 238개, 실제 전투/미리보기 기본 300·처치 45개 대조, 튜토리얼, 무작위 입력 4시드, 이어하기, 온라인·패치 표.
- 최종 카드 헤더 갱신 정리 후 명세 238개 및 폰 모의 길목 경고·터치 시작 검사 재통과.
- UI 빈도 측정 완료. 헤드리스 측정이므로 실제 GPU·실기기 성능을 증명하지 않는다.
- 서버 Python 검사는 의존성 부재로 생략. 실기기·실제 멀티플레이 미검증. native 검사 종료 시 ObjectDB 잔존 경고가 있다.
