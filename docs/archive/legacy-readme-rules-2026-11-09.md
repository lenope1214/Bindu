## 오브젝트 구조
오브젝트 = **공격방식(형태) + 속성(효과) + 강화 + 연계**. 쉬는 시간 선택지에 네 종류가 섞여 나온다.

- **새 오브젝트**: 속성 카드를 빈 곳에 놓으면 *직선탄 + 그 속성*으로 설치.
- **공격방식**: 직선탄인 오브젝트에 한 번만 넣을 수 있고 그 뒤로 고정. 같은 공격방식을 또 넣으면 레벨업(피해·속도·사거리).
- **속성**: 오브젝트 위에 놓으면 겹치기. 한 오브젝트에 3종까지(같은 속성은 Lv5까지), 더 섞으려면 연결선으로 나눔. 모든 공격에 겹친 속성 전부의 부가효과가 붙고, 속성이 많을수록 피해 증가, 대신 종류가 늘 때마다 공격 속도가 느려짐(버전 1 기준 2종 -13%, 3종 -23%).
- **강화**: 오브젝트 위에 놓기. 종류마다 5개까지 쌓임(규칙 버전에 따라 다름). 넣을 곳이 없는 강화·공격방식 카드는 선택지에 나오지 않음.
- **연계**: 연결선(두 오브젝트), 프리즘·공명(한 오브젝트).

| 공격방식 | 형태 |
|---|---|
| 직선탄 (기본) | 정한 방향으로 탄 |
| 분사 | 부채꼴 지속 피해 |
| 관통 연사 | 작은 가시를 빠르게, 관통 |
| 물줄기 | 주기적으로 길게 뿜어 멈춰 세움(경직) |
| 연쇄 번개 | 앞쪽 구체를 치고 주변으로 튐 |
| 돌풍 | 넓은 바람, 옆으로 밀기 |
| 파편탄 | 맞으면 파편 3개 |
| 벽 | 앞에 바위 벽(최대 2개) |
| 블랙홀 | 구체가 가장 많이 모인 곳에 중력 우물을 떨어뜨려 가운데로 끌어모으고, 안 구체가 남에게 받은 피해 20%를 모았다가 끝에 터짐 |
| 레이저 | 충전 후 화면 끝까지 관통 |
| 투척 장판 | 느린 탄이 지나간 자리에 속성 장판 (유도하면 휜 길 그대로) |
| 철구 | 느리고 무거운 관통탄 |
| 음파 | 부채꼴로 퍼지는 파동 (관통, 끝에서 피해 50%) |
| 시계침 | 앞쪽 ±0.7라디안을 바늘이 왕복하며 훑음 (한 번 훑을 때 같은 구체는 한 번) |
| 혼불 | 오브젝트 곁(목줄 300 안)을 떠돌며 가까이 온 구체를 쫓아 때리는 혼불 2개(+다중 발사), 6초 뒤 사라지면 1.2초 뒤 다시 |

| 속성 | 부가효과 |
|---|---|
| 불 | 화상 |
| 나무 | 피해 20% 증가 |
| 물 | 감속 |
| 전기 | 주변으로 튀는 전류 (확률 30%) |
| 바람 | 둘레(240) 다른 오브젝트 공격 속도 +8%/레벨 (가장 큰 바람 하나만) |
| 얼음 | 냉기 누적 시 빙결 |
| 땅 | 기절 (확률 20%씩) |
| 어둠 | 2초간 받는 피해 +30% |
| 빛 | 치명타 2배 (확률 12%씩, 최대 60%) |
| 독 | 중독, 죽으면 주변 전염 |
| 금속 | 추가 피해 + 경직(제자리에 잠깐 멈춤) |
| 소리 | 울림: 3초간 어느 오브젝트에 맞든 울림이 쌓여 3번째마다 주변(70)에 음파 (같은 구체는 1초에 한 번) |
| 시간 | 메아리: 2초간 받은 모든 피해의 20%(레벨마다 +5%, 최대 40%)를 끝날 때 한 번 더 |
| 영혼 | 넋: 맞고 3초 안에 죽으면 확률(28%, 레벨마다 +8%, Lv5 60%)로 혼불이 나와 다른 구체를 쫓음 |
| 별 | 별빛: 둘레 220 안 다른 오브젝트 피해의 10%(레벨마다 +3%)·자기 피해 20%를 복사해 모으고(별만 들면 x1.5), 웨이브 구체 체력 x8이 차면 구체가 가장 모인 곳에 초신성(별빛 x3, 모은 속성 부가효과·반응). 별 + 속성 하나는 그 속성의 행성: 둘레 피해 중 그 속성 몫만 30%로 모으고 초신성 뒤 행성 효과. 같은 행성은 한 판에 하나, 행성은 3개까지 |

| 강화 | 효과 |
|---|---|
| 다중 발사 | 공격 1개 추가 (각 55%, 쌓을수록 조금씩 줄어듦) |
| 분열 | 맞은 구체에서 약한 파편 2개 (확률 12%씩, 최대 60%) |
| 반응 | 사거리 안 가장 가까운 구체를 전방위 자동 조준. 최종 피해 -10%, 오브젝트당 1개(모든 모드). 혼불·블랙홀 제외 |
| 유도 | 탄이 구체 쪽으로 천천히 휨(휜 90도마다 피해 -15%, 최저 55%), 범위 공격은 구체 쪽으로 조금 돎 |
| 튕김 | 탄이 가까운 구체로 튐(튕긴 탄 피해 40%), 번개 +1회, 그 밖은 피해 +4% |
| 크기 | 크기·범위·사거리 +12%, 탄은 피해도 +4% |
| 속사 | 공격 속도 +10% |
| 관통 | 탄 1개 더 관통(뚫을 때마다 피해 절반), 그 밖은 피해 +6% |

효과가 없는 조합은 넣을 수 없음(`Pat.NO_MOD`): 관통 연사·돌풍·철구 ✕ 관통·튕김(원래 모두 뚫음), 벽 ✕ 유도(정한 방향에만 섬), 벽·투척 장판 ✕ 분열(바닥에 남아 때리는 피해는 분열을 일으키지 않음. 날아가는 블랙홀은 끝에서 터질 때 분열). 이런 강화가 든 직선탄은 그 공격방식으로 바꿀 수도 없음.

|---|---|

특수 반응은 공격방식과 별개로 추가 공격이 나간다. 두 속성 조합 91개 모두에 반응이 있다(속성마다 13개, 2026-10-30에 빈 칸 65개를 채움, 코드는 scripts/rx_more.gd).
새로 채운 65개는 물=앞으로 흘러가는 물결(지나간 자리에 물길 2초), 땅=앞으로 뻗는 균열(지나간 자리에 띠 2초), 바람=앞으로 떠감, 빛=즉시 광선으로 모양을 정한다 (오브젝트에서 고정 거리에 생기는 장판은 없음). 독·바람·얼음·땅이 들어간 것은 위력을 약 20% 높게 잡았다.
기존 26개의 반응 모양은 한쪽 속성이 정한다: 물이 들어간 반응은 공격 방향으로 흐르는 물길(웨이브가 시작되면 앞으로 흘러 나감), 땅은 오브젝트 공격이 맞힌 구체에 붙음(용암 폭발·독늪 늪·모래시계 되감기), 소리는 앞쪽 부채꼴 파동, 시간은 잠시 뒤 같은 공격이 한 번 더, 영혼은 쫓아가는 혼불.

## 특성 (5웨이브마다)
보스 웨이브를 넘길 때마다 3개 중 1개를 고른다. 같은 특성을 여러 번 고를 수 있다.

| 특성 | 효과 |
|---|---|
| 화력 | 모든 피해 +15% |
| 속사 | 모든 공격 속도 +12% |
| 원거리 | 모든 사거리 +12% |
| 단단한 중앙 | 중앙 최대 체력 +3, 모두 회복 |
| 넉넉한 선택 | 쉬는 시간마다 새로고침 +1 |
| 행운 | 속성 카드가 Lv2로 나올 확률 +20% (기본 20%에서 웨이브마다 +2%, 최대 50%에 더함) |
| 회복 | 웨이브를 마칠 때마다 중앙 체력 +1 |
| 끈적한 공간 | 모든 구체 이동 속도 -8% |
| 조화 | 속성을 여러 종류 겹쳐 생기는 공격 속도 감소가 절반으로 (버전 1: 2종 -13% → -7%, 3종 -23% → -13%). 한 번만 고를 수 있고, 올려 주는 공격 속도는 최대 +20% (도파민 3종까지는 그대로) |

## 규칙 버전 (시작 화면에서 선택, 저장됨)
2026-10-30 결정으로 두 버전만 고른다. 버전 1은 예전 버전 2(분산: 연결 거리·무리 보너스)와 4(카드 2장·이른 특수 구체)의 좋은 점을 넣어 고쳤고, 버전 3도 공통 항목은 1과 같다. 그래서 둘을 비교하면 "상한 vs 대가"만 다르다. 고친 뒤로 최고 기록은 새로 시작하고, 그 전 기록은 기록 화면에 "이전 규칙"으로 남는다. 예전 버전 2·4와 폐기한 5로 저장된 이어하기는 버전 1로 이어진다. 수치는 `scripts/rules.gd`.

요청된 개선 작업 목록과 진행 상태는 [docs/improvements.md](docs/improvements.md)에서 관리한다.

| 버전 | 바뀌는 점 |
|---|---|
| 1 기준 | 속성 3종·강화 종류별 5개. 쉬는 시간마다 카드 1장(처음 두 번 2장), 오브젝트 수 보너스(5개 +16%·10개 +23%, 로그 곡선), 연결선 거리 420, 저항 구체 10웨이브·굳센 구체 13웨이브부터, 11웨이브부터 체력 +5%씩 |
| 3 자유 쌓기 | 상한 없음. 대신 속성 종류마다 공격 속도 -25%(기본 -15%), 같은 강화는 쌓을수록 효과가 절반씩(1, 1.5, 1.75…). 그 밖은 버전 1과 같음 |

코드에만 남아 있는 예전 버전(봇 비교용, `RULES=2` 등): 2 분산형(속성 2종·강화 3개·무리 +6%, 지금은 같은 곡선 계수 0.15), 4 빠른 템포(체력 +8%·특수 구체 8·11웨이브·구체 1.4배). 5 조합형(강화 칸)은 2026-10-30 "너무 어렵다"는 반응으로 폐기하고 코드를 지웠다(예전 기록만 "이전 규칙"으로 남음). 경위와 새 규칙 버전을 내기 전 점검 절차는 [docs/rule-history.md](docs/rule-history.md).

## 규칙
- 구체 종류: 일반(원), 빠른(뾰족, 4웨이브~), 단단한(네모, 7웨이브~), 보스(5웨이브마다, 중앙에 닿으면 3 피해, 부하 소환. 앞 쉬는 시간에 체력·저항과 실제로 지나갈 길을 분홍 선으로 미리 보여 줌). 8웨이브부터 보호막, 12웨이브부터 분열 구체가 섞임.
- 웨이브 구체 수는 3 + 2×웨이브. 150웨이브(303개)에서 수가 고정되고 이후 초과 몫은 구체 체력에 반영됨. 새 진입 방향이 열리는 웨이브(3·6·9·18·24)는 구체 20% 적게. 보스 부하는 첫 보스 7초마다, 웨이브가 오를수록 빨라져 13웨이브부터 4초마다.
- 누수: 중앙에 닿은 구체가 나온 화면 가장자리가 붉게 번쩍이고, 다음 쉬는 시간 안내 첫 줄에 "지난 웨이브 누수: 북동쪽 3개 · 서쪽 1개 (빠른 3, 일반 1, 중앙 -4)"처럼 어디서 무엇이 새었는지 보여 줌.
- 11웨이브부터 구체 체력이 웨이브마다 5%씩 곱으로 늘어남. 10웨이브부터 저항 구체(그 웨이브의 저항 속성은 미리 안내, 그 속성 비중만큼 피해 최대 60% 감소, 점선 고리), 13웨이브부터 굳센 구체(밀기·감속·기절·냉기 절반, 회색 쐐기).
- 군중 제어 한계: 감속은 최대 70%(보스 50%), 중앙 반대쪽으로 밀리는 거리는 여유 40만큼(천천히 회복), 기절·속박·빙결은 연달아 걸리면 100%→50%→25% 뒤 2초 면역. 보스는 기절 시간 절반.
- 무리 보너스: 오브젝트 하나당 모든 오브젝트 피해 +3%. 특수 반응 공격은 겹친 레벨 합 배율을 받지 않고 반응 레벨로만 강해짐.
- 연결선은 두 오브젝트가 320 이내(버전 2는 420)일 때만 작동. 옮겨서 멀어지면 빨간 점선으로 끊김.
- 맵 5종: 평원·소용돌이·십자로·폭풍·회랑(시험, 가로 일자 길, 시작 화면에서 구체가 오는 쪽을 고름). 맵별 최고 기록, 업적으로 모양 해금.
- 보스를 처치하면 중앙 체력 +2, 새로고침 +1.
- 구체는 화면 밖에서 중앙 점으로 이동. 다음 웨이브의 진입 방향이 빨간 화살표로 미리 표시됨. 방향은 웨이브마다 유지되며 점점 늘고(4곳 뒤로 6웨이브마다 하나씩, 최대 6), 가끔 하나가 옮겨 감. 발사체로 맞혀 처치하면 점수(최대 체력×10).
- 오브젝트는 체력이 없어 부서지지 않음. 구체는 오브젝트를 그냥 지나감.
- 중앙 점 체력 10, 구체가 닿으면 -1, 0이면 게임 오버. 웨이브는 무한.
