# 빈두 (Bindu)

사방에서 몰려오는 구체가 화면 중앙의 점에 닿기 전에 막아 내는 로그라이크 디펜스 게임입니다.

웨이브를 막을 때마다 카드 세 장 중 하나를 골라 오브젝트를 세우고 키웁니다. 한 오브젝트에 여러 속성을 겹치면 장작, 증기, 감전, 용암 같은 특수 반응이 생깁니다. 광고와 결제가 없습니다.
