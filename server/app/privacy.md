# 빈두(Bindu) 개인정보처리방침

시행일: 2026년 11월 3일

빈두(이하 "게임")는 회원 가입이나 로그인 없이 플레이할 수 있는 게임입니다. 이 문서는 게임이 어떤 정보를 서버로 보내고, 어떻게 쓰고, 언제 지우는지 설명합니다.

## 1. 보내는 정보

게임 설정의 온라인 기능(판 기록 보내기)이 켜져 있을 때 아래 정보를 게임 서버(bindu.anon-chat.kr)로 보냅니다. 처음에는 켜져 있고, 설정에서 끄면 플레이 기록과 오류 기록을 보내지 않습니다.

- 기기 id: 게임을 처음 켤 때 기기 안에서 만드는 무작위 문자열입니다. 기기의 광고 id, 전화번호, 하드웨어 식별자와 관계가 없습니다.
- 닉네임: 직접 입력한 경우에만 보냅니다. 비워 두면 "익명"으로 표시됩니다. 실명을 입력하지 마세요.
- 플레이 기록: 게임 버전, 플랫폼(Android 등), 맵, 규칙·모드, 웨이브, 점수, 플레이 시간, 고른 카드와 오브젝트 구성.
- 오류 기록: 게임에 오류가 났을 때 오류 내용, 게임 버전, 운영체제 이름과 버전.
- 게임 진행: 다른 기기에서 이어 할 수 있도록 맵별 최고 기록, 업적, 도감, 처치·판 수, 고른 맵·모양 등과 이어하던 판의 저장. 서버는 기기마다 무작위 비밀값을 받아 되돌릴 수 없게 변환한 값(해시)만 저장해 그 기기를 확인합니다.
- 신고: 리더보드·멀티 방에서 다른 플레이어 닉네임을 신고하면 신고한 계정, 신고된 이름, 까닭을 저장합니다.
- 다음 패치 투표: 투표 창에서 직접 넣은 표(항목·방향)와 적은 한 줄 의견. 계정에 묶어 저장합니다.
- 멀티플레이: 방을 만들거나 들어가면 방 코드 중개와 연결 중계를 위해 Cloudflare(Workers·TURN)를 거치며, 같은 방 플레이어끼리는 직접(P2P) 연결되어 서로의 IP 주소가 연결에 쓰입니다. 닉네임과 플랫폼 종류가 같은 방 플레이어에게 보입니다. 중개 서버는 방이 끝나면 방 정보를 지웁니다.
- 접속 IP 주소: 서버는 IP 주소를 그대로 저장하지 않고, 되돌릴 수 없게 변환한 값(해시)만 저장합니다.

기록 보내기를 꺼도 게임을 켤 때 새 버전·밸런스 패치를 확인하려고 게임 버전과 플랫폼을 보내고, 리더보드를 열면 내 순위를 표시하려고 기기 id를 보냅니다. 이때 서버는 아무것도 저장하지 않습니다.

이름, 이메일, 전화번호, 위치, 연락처, 사진, 결제 정보는 받지 않습니다.

## 2. 쓰는 곳

- 리더보드 표시 (닉네임, 점수, 웨이브)
- 게임 밸런스 조정을 위한 통계 (카드 선택률, 평균 웨이브 등)
- 다음 패치 방향을 정하기 위한 투표 집계
- 오류 수정
- 멀티플레이 방 연결 (Cloudflare)
- 부정 기록과 과도한 요청 차단 (IP 해시)
- 부적절한 닉네임 처리: 신고가 들어오면 운영자가 24시간 안에 확인해 이름을 지우거나 해당 기기·계정을 차단합니다

광고, 마케팅, 맞춤형 광고에는 쓰지 않으며, 다른 회사에 팔거나 넘기지 않습니다. 게임에는 광고와 외부 분석 도구가 없습니다.

## 3. 보관 기간

- 오류 기록: 30일 뒤 자동 삭제
- 플레이 기록과 닉네임: 리더보드·통계 운영 기간 동안 보관하며, 삭제를 요청하면 지웁니다.
- 게임 진행: 계정이 있는 동안 보관하며, 삭제를 요청하면 지웁니다. 이어하던 판은 30일 뒤 자동 삭제됩니다.

## 4. 전송 보안

모든 전송은 HTTPS로 암호화됩니다.

## 5. 삭제 요청과 문의

게임 안에서 바로 지울 수 있습니다: 설정 → [내 온라인 데이터 지우기]를 두 번 누르면 서버의 계정·게임 진행·이어하던 판·투표를 지우고, 리더보드에서 이름과 기록을 뺍니다(남은 판 기록은 이름 없이 통계로만 남습니다). 그 뒤 기록 보내기는 꺼집니다.

기록 삭제를 원하거나 궁금한 점이 있으면 아래로 알려 주세요. 게임 설정에서 확인할 수 있는 닉네임과 대략의 플레이 날짜를 함께 알려 주시면 해당 기기의 기록을 찾아 지웁니다.

- GitHub: https://github.com/lenope1214/bindu/issues

## 6. 아동

게임은 아동을 주 대상으로 만든 서비스가 아니며, 이름·연락처 같은 개인정보를 받지 않습니다. 보호자는 설정의 [내 온라인 데이터 지우기]로 서버에 저장된 정보를 언제든 지울 수 있고, 기록 보내기를 끄면 기록이 서버로 가지 않습니다.

## 7. 변경
